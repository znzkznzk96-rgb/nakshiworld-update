## 남은 작업 및 순서
1. v1.06 전체소스 확보·검증. 터미널의 같은 실패 다운로드를 반복하지 않는다. PNG 전용 CI가 동작한 GitHub Actions에서 Release ZIP 확보·기록 SHA 검증 및 필요한 복원/렌더를 수행하는 경로를 다음으로 검토한다. 이 새 소스 확보 작업은 아직 실행하지 않았다.
2. 전체소스에 활성 overlay와 삭제명세를 적용하고 staging의 검증 PNG만 선택 반영한다. staging 전체 병합으로 전송 조각·진단 workflow가 게임 작업에 섞이지 않게 한다.
3. 낚시/낚시터 선택 두 화면의 경로·표시 크기·수면/발판/캐릭터 위치와 ASSETS·관련 테스트를 801×1962 승인본에 맞춘다. 기존 809×1944/구경로를 그대로 사용하지 않는다. 실제 화면 비교를 준비되는 즉시 보여준다.
4. 물고기20종 승인본 일치(12/17 포함)·도감 표시 검증. 번들 메인6/서브6/주인1, 계곡 보상 수령 후312,000비늘 해금, 기증·보상 중복 방지·저장실패 롤백·재접속을 격리 세이브로 검증한다.
5. 기존 세이브·공통 시스템 전체 회귀검사 후 배포본 구성. 공개 배포·운영 ZIP/PCK/version.json 실제 다운로드·휴대폰 확인은 각각 구분한다.
