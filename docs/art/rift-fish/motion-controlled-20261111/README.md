# 3종 원화 제어 모션

승인 원화의 픽셀을 샘플링하는 재현 가능한 오프라인 리그다. 새 유료 생성이나 거절된 생성 프레임의 보정본이 아니다. 16프레임·16fps·좌향, 게임 적용 전 사용자 시각 검토 대기.

원화: `../motion-hd-20261111/{14,17,18}/base-1/original.png`. 각 파일을 이 폴더의 `14.png`, `17.png`, `18.png`로 복사한 뒤 `godot --headless --path . --script make_motion.gd` 실행. 이번 도구는 Godot4.6.3, 게임4.4.1검사/통합은 미수행.

프레임 ZIP은 생성16PNG만 포함한다. 원화와 다르게 여백을 추가했으며 본체픽셀은 확대하지 않는다. 고정캔버스:14=296×284,17=296×216,18=296×236. 원본 배치 오프셋=(32,40), 프레임마다 개별bbox로맞춤확대금지. 실제 표시 배율은 RIG_REPORT의 fight_scale을 사용한다. preview.gif는 편의용 팔레트미리보기, 정확한자산은PNG ZIP이다.
