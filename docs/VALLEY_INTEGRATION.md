## 최신 확정 설계와 미정 항목
기준은 docs/GAME_BIBLE.md. 아래 과거 해금/주인 제안은 사용하지 않는다.
- 메인 번들 완료 → 해당 급수 자격증 및 다음 낚시터 구매 자격 → 별도 비늘 지불. 번들 어종/마릿수 미정이므로 준비 중 유지. 도감60%/12종 발견을 임의 필수조건으로 사용하지 않는다.
- 해당 지역 모든 파츠 장착 후 주인 게이지 누적. 100% 다음 물고기는 주인. 놓치면70%, 잡으면0%. 증가량/횟수는 기존 기획을 먼저 확인하며 없으면 미정 유지.
- 20종 평균/최대 길이는 GAME_BIBLE 표로 확정. 판매가/무게/전투수치는 별도 미정.

## 자동으로 처리할 기술 작업
- 저수지 sp0~19 보존, 계곡20~39로 영구 구분. 두 지역 버들치 기록 충돌 방지용 지역+종ID키, 기존 이름기반 DEX/REC/catch_counts 마이그레이션.
- 가방/판매/손질/수족관/도감/최대어 표시 모두40종 대응. 저장·재시작·지역 왕복 검증.
- 지역선택→실제해금→상점/미끼 연결. 미완성 지역2~5는 잠금 유지. 별도 박물관 번들 기부/보상은 기존 준비중 유지, 이번 요청에 임의 추가하지 않음.
- 상세배경 원본 유지. 구름은 하늘영역에 한정하여 절벽/부유섬 앞을 덮지 않게 마스크. 역류폭포는 수면→오른쪽 섬 상단으로 올라가는 시간방향 검증. 잔물결/반사/수중빛 각각 독립 레이어. 기존 의자/캐릭터/낚싯대 끝/찌/수면 동시 정렬.
- 1080x2640 세로 실제렌더 확인, 화면비 변경시 잘림·늘어짐·UI충돌 점검. 유료 생성/AI업스케일 금지 유지.
- 공개 전 복원 workflow를 최신전체소스 기반/삭제목록 지원으로 보완. 현 workflow는 과거PCK복원+overlay라 삭제 미반영.
