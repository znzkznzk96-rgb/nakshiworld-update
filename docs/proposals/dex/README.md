# 개인 기록 도감 3시안 — 2026-10-23

사용자 요청에 따른 검토본. 선택/게임 도감 교체/저장 스키마 변경/배포 없음.

- 수집 도감: 어종 타일에서 종 선택, 최고 개체등급·최대길이·최대무게 별도 개체 정보 동시 노출.
- 트로피 전시: 한 어종의 기록 종류를 바꾸며 해당 기록 개체를 크게 전시. 등급 수집5단계 별도 표시.
- 낚시 기록장: 세 최고기록 요약과 길이/무게/등급 경신 이력. 날짜/증가량은 신규 기록 저장이 필요한 제안.

모든 수치·날짜·수집 진행률은 가상 예시. 어종 별과 개체등급 분리. 메뉴 도감은 개인기록으로, 기증/번들은 마을 박물관에 남기는 방향. 선택 전 런타임 메뉴 변경하지 않았다.

현재 저장은 DEX 등급·REC 최대길이·등급별 catch_counts 중심. 최대무게 개체/각기록 날짜와 길이·무게 동시 정보는 누락 가능. 구현 시 지역ID+어종ID로 3개 독립 최고기록을 저장하고 판매/손질/기증 후에도 유지해야 한다. 과거 누락 필드는 `기록 없음`으로 두고 추정 복구하지 않는다. 보유 개체 역산을 역대 최고기록으로 표시하지 않는다. 기록장 이력은 새 수집 시작 시점부터 표시해야 한다.
