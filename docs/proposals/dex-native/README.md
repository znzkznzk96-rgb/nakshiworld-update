# 도감 V2 — 실제 게임 UI 재사용 3시안

2026-10-23 사용자: 구성은 좋으나 기존 HTML 시안은 게임UI와 달라 거절. 본 V2는 실제 Godot main.gd의 sb_panel/sb_btn/sb_chip/hud_reference_style, ui_theme.title, icons.close, _ui_fish, 기존 글꼴/text_layer를 직접 재사용한다. 새 UI 스킨·유료 아트 생성 없음.

수집 도감: 8개 어종 타일과 선택 어종의 최고 등급/길이/무게를 동시에 표시.
트로피 전시: 기록별 개체를 큰 그림으로 보여주는 상세 화면과 등급 수집.

모든 수치·날짜·수집률은 가상 예시다. 같은 붕어라도 세 최고기록은 별개 개체. 기존 박물관/실제 도감·저장구조는 변경하지 않았다. 선택대기, 미배포.
