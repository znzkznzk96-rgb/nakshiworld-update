# 강화 오라 V2 — 저강화 보강·실제 최대20 반영

사용자 +2/+4/+6 가시성 부족 지적을 반영했다. ROD_MAX=[5,8,10,13,16,20] 실제값을 확인했으며 이전 최대10 표기는 잘못된 부분시안이었다. 변경된 색 조합은 사용자 검토 전 제안이다. 게임 연결·배포 없음.

0~10은 앞14초, 0/12/14/16/18/20은 뒤14초, 전체28초/24fps. 모든 칸은 실제최대20의 은하낚싯대 외형/동작으로 비교한다. 절대 강화2회마다 단계 변경, 홀수는 직전짝수단계 유지. 낚싯대별 최대강화/성능/세이브는 변경하지 않았다. 저단계의 두께·채도·입자·발광과 선명한 은백색 윤곽을 확대했다. 무지개 최종단계는20으로 이동.

복원은 v0.71 전체소스+활성브랜치overlay/삭제명세. 이폴더4개gd파일을 프로젝트 review_aura/로 복사한 뒤 Godot4.4.1 `--path <project> --script review_aura/render_review.gd -- <output>`로 그래픽환경에서 실행. 672장의1080x800PNG를24fps로 인코딩한다. `ffmpeg -framerate 24 -i <output>/%04d.png -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart NAKSHIWORLD_ROD_AURA_V2_TO20.mp4`.
