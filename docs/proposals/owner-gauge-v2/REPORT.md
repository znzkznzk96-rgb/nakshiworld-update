# 우주바다 기준 주인 게이지 재시안

사용자 요청: 우주바다 프레임 분위기를 공통으로 사용하고, 지역 컨셉을 살리면서 높이를 조금 줄여 6종 재시안. 이번 결과는 제안용이며 게임 적용/배포는 하지 않았다.

- 기존 256×64 → 원본 256×48px (높이25% 축소). 실제 기존 우주 프레임을 스타일 및 형태 참조로 전송했다. 참조색 고정은 끄고 지역별 팔레트를 사용했다.
- 지역별1회·총6요청/6결과/60생성회분·재생성0. 각 디렉터리에 원본 PNG, request/provenance/submission/receipt/review 보존.
- 저수지: 청룡 비늘/상아·금 장식. 계곡: 역류·청록/은색. 타일바다: 도자기/청백 모자이크. 균열해역: 선박금속/보라. 심해: 산화청록·구리 배관. 우주바다: 남보라·별빛/은색.
- 모음은 이름/73%/진행바와 승인된 저수지·계곡 주인 그림을 합성한 시안이며 엔진 화면이 아니다. 후속4지역 그림칸은 비워두었다.
- 원본 좌우 투명 여백이 서로 달라 모음에서는 알파 사용영역의 가로범위만 잘라 공통256px 표시폭에 nearest 보간했다. 세로0~48은 유지했다. 원본 PNG 바이트는 수정하지 않았다. 글자는 표시변환 후 동일 크기로 합성했다.
- 6종 원본치수/해시/receipt/시안 품질을 확인하고 모음과 높이 비교를 육안 검수했다. 가장자리 가는 장식과 실제게임 좌표는 선택 후 적용 시 추가 조정 대상이다. 시안 통과를 제작완료/실제게임 QA로 해석하지 않는다.
