# 0.64 지역 상점·인수인계

현재 spot_selection.gd의 지역명/해금비 사용. 신규5지역 파츠4종과 가이드책 총21자산은 PixelLab API v2 개별생성. 요청/해시: PIXELLAB_064.json. 5개 묶음 시안은 잘못된 도구가 섞여 미채택. 인증키는 비공개 원본 인수인계 keys/pixellab.key, git/문서에 값 저장 금지. 플러그인 검색만으로 연결 부재를 단정하지 말 것.

파츠 임시 가격: 저수지165/330/594/990 유지. 신규 찌/바늘/줄/릴 = 해당 해금비의5%/10%/18%/30%,10비늘 단위 반올림. 같은 종류 하나만 장착, 기존 장비/탈착/판매/재구매 통합. 성능은 기본 파츠와 같은 별2/3/4 해금. 릴은 주인낚시 준비이며 아직 주인 미구현. 기존 코드에 없는 줄 충격감소 효과를 추가했다고 주장하지 않는다.

미끼는 기존 plan_live.md의 6종: 지렁이10×1.0, 갯지렁이60×1.25, 새우300×1.5, 오징어1200×1.8, 황금루어3000×2.1, 전설미끼6000×2.5. 지역 인덱스0/1/3/4/4/5(저수지/계곡/선상/심해/심해후반/우주)에 해금. 등급 가중치 multiplier^등급 후 정규화; 별 확률과 별개. 수량1/5/10/50/100. 미끼 이름을 눌러 사용 선택, 재고가 없으면 지렁이→맨바늘 순. 기존 m.bait 보존, 고급미끼재고/선택/지역은 추가 region_shop 세이브필드.

신규5낚시터는 실제 플레이 구현 전. 비용만 받고 미완성 지역을 열지 않는다. 기본 region_shop.unlocked=[0]. 향후 지역 콘텐츠와 도감·주인·돈 조건을 검증한 진행 처리에서 region_shop.unlock(m,index) 호출하면 상점/미끼가 함께 풀린다. 이 함수는 순차 해금만 검증한다. 현재 낚시터선택은 미완성지역 진입 불가. 이번은 미래 지역용 상점 준비이며 신규5낚시터 완성으로 보고하지 않는다.

계측: 저수지 신규개체 최대150cm, 종별 평균×1.65와 지역한도 중 작은 값. 기존 평균/표준편차 유지, 극단 꼬리 제한. 어종 고정눈금10/20/30/50/100/150cm. 옛 세이브·기록 보존. 현실 생물학 최대치가 아닌 게임 설계 한도.

박물관: 어종20·등급100 수집 진행, 개인최대어 표시. 신규 경제보상/기부/업적 보상 없음.

배포 우편: automation/release-history.json 단일 원본. prepare_release.py가 release_notes.gd/GitHub Release 본문 생성. 현재 버전과 첫 우편ID 불일치·중복·빈본문은 배포 차단. 읽음/삭제ID 유지. 미확인0.58~0.60 변경점 임의 생성 안 함.
