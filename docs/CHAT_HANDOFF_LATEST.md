- 배후의 산천어 l1_19: boss-wave5 결과. 작은 입, 긴 붉은 테두리 물결/리본 지느러미. 사용자가 외형 좋다고 명시.
- 은어 대신 조약돌고기, 꺽지 대신 나뭇잎꼬리 이름 확정.

## 배경 제작에서 반드시 지킬 사용자 요구
- 저수지와 비슷한 '구도'는 왼쪽 캐릭터 낚시자리, 수면 높이, 아래 수중 플레이 공간을 뜻한다. 오두막/바닥/배경을 복사하라는 뜻 절대 아님.
- 화폐를 벌어 새 지역을 해금했을 때 새로움을 느껴야 한다. 저수지 노란 모래바닥/평범한 산/오두막을 그대로 재사용 금지.
- 스토리는 이상현상. 폭포는 반드시 위로 역류. 위로 솟는 물방울/돌과 역중력 지형 등으로 상하부 모두 차별화.
- 마지막3안의 기반은 이전 anomaly_01 녹색 역중력 협곡 분위기. 그 분위기는 선호했으나 잔디테일 과다/지저분함과 앉을 자리 부족을 지적함.
- 캐릭터가 실제로 앉고 장비를 놓을 넓고 평평한 전경 바닥. 낚싯대/캐스팅 앞 공간 확보. 작은 먼 절벽 산책로로 대체 금지.
- 도트가 보이는 깔끔한 픽셀 묶음, 제한된 명암, 큰 지형 덩어리. 잎/잔돌/물보라 과잉 금지. 수중 중앙은 물고기 컨트롤 가독성을 위해 비운다.
- 정지 그림의 상향 분수만으로 완전한 역류 표현이 보장되지 않음. 일부 시안은 내려오는 폭포처럼 보임. 채택본에서 방향 명확화와 실제 상향 애니메이션 검증 필요.
- 배경시안은 built-in 이미지 생성으로 제작. PixelLab으로 만들었다고 말하지 말 것.

## PixelLab 물고기 제작 이력과 비용 주의
유료 API 키를 원래 사용자 자료에서 받아 사용했으나 이 백업에는 넣지 않음. 연결상태는 새 환경에서 확인하고 키를 채팅에 요구하지 말 것.
기록상 호출: 최초 실패20 + 단일잎꼬리 실패1 + v2작업21(초기 style실패1/Pixflux20) + revision3 2 + revision4 3 + boss_wave5 1 =48회. 이는 이 인수인계에 남은 작업 기록 합계이며 계정전체 청구명세를 조회한 값 아님.
실수: 임시 시안 색을 init로 넘기고 금빛 붕어 공통 강참조 사용, 명암/형태 미달 후 후속 호출 계속한 사례. 재발 방지 규칙은 docs/FISH_ART_RULES.md. 유료 요청은 사용자 요청범위, 한 종 생성 후 검수, 무단 후보/자동 재시도 금지.
사용자 선호: 색 진하고 종별 주조색이 겹치지 않게, 저수지20종과 일관된 비늘/명암/외형 특징. 평평한 아이콘/물빠진 색 금지.
