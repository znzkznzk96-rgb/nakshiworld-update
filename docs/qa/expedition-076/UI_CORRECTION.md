# 확정 UI 누락 정정 / 수정본

v0.76 기능검사는 통과했지만 확정 시안 충실도는 실패했다. 탐험/연성 아이콘을 임의의 저밀도 SVG로 대체, 열 방 배경을 반복 도형으로 대체, 메뉴 순서와 연성 배치를 변경했다. 최종시안 적용완료라는 보고를 정정한다.

## 이번 수정
- 사용자 재첨부3장 그대로 게임 아틀라스로 사용. 원본 픽셀 변경/재생성/유료생성 없음. 첨부 확장자는PNG지만 실제포맷JPEG라 .jpg로만 이름변경. SHA256은동일.
- 메뉴: 낚시터·가방·도감·탐험·연성·설정. 원본 문/나침반과 쌍어혼솥을 포함한6아이콘,순차등장과살짝커졌다돌아오는팝업.
- 노선도: 원본10카드의서로다른방/명칭/3·5·7해골/10왕관을직접연결,지그재그연결선/선택청록테두리. 기존반복도형방함수제거.
- 마을: 크림장소·퍼센트제목줄+원본방배경+실제전투모션. 라벨이나해골이배경에묻어나지않도록방그림영역만사용.
- 연성:어혼연성/병사합성2탭,두소재카드와+,아래결과미리보기/역할,보유어혼5종/수량,청록실행버튼. 병사보관은상단별도버튼. 기존확정병사·5어혼원본/15레시피/모션/전투·합성수치/저장유지.
- 편성3칸은유지하고칸을누르면병사선택판. 이미편성한병사선택은자리교환;비우기는명시버튼;드래그순서변경유지.

참조그림의3개고정하단탭은후속확정6개메뉴로대체된이력이므로추가하지않음. 원본게임테두리/폰트는네이티브UI로유지하며전체정지시안스크린샷을조작화면인것처럼덮지않음. 카드아트/아이콘만아틀라스,재화/편성/어혼/상태/버튼은실제데이터와연결.

검증: 실제Godot480/540/660높이렌더,메뉴순서/원본AtlasTexture사용/편성선택·교환·제거입력검사. 기능회귀검사와시안비교를구분. 수정본은 work브랜치에저장하며현재운영0.76은아직교체하지않음.
