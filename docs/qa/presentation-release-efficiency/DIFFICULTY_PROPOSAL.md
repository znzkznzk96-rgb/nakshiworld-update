- 장력: 지속 저항/순간 돌진을 분리하고 지역하중과 장비제어력을 별도 계산. 단순 지역배수만 곱해 즉사시키지 않는다.
- 몸짓: 지역별 돌진 비중/빈도·회복창을 차등. 명확한 예고는 유지하고 장비부족을 예고삭제/무작위실패로 표현하지 않는다.
