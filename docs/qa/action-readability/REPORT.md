# 초기지역 물고기 액션 가독성 개선
2026-10-23. 기존전투 유지, 공개배포 없음.
- 저수지3종(돌진/역돌진/점프), 어종ID로 대표행동 고정. ★1은1종, ★2는일부2종, ★3~4는2종, 주인은3종. 계곡은 일부 어종에 잠수로 대체. 등급이 행동종류를 추가하지 않는다.
- 초기두지역 전조0.8~1.1초. 가짜전조/가짜휴식/연속기습/무작위spike 제외. 기존 swim/rest 무작위 선택과 포획진행식 유지. 강제회복단계/강제1~3회포획 없음.
- 돌진0.9~1.8초에 기존등급/혼돈배율, 역돌진1.5~2.1초, 잠수1.05~1.65초에 등급배율. 점프1.2초·착수0.5초. 착수구간엔 다음공격 안겹침. 뒤 미구현지역의 레거시 패턴 배치는 유지.
- 잘못감는 돌진/잠수의 양수 텐션속도25% 가산. 점프공중 가산90→105/초. 초기충격량과 역돌진 정답감기 그대로. 줄느슨함즉시초기화 등 별도 구조개편은 보류.
- 줄색40%주황/65%빨강/85%진홍, 연속보간. 고위험줄끝0.65픽셀미세떨림. 텐션게이지 기준색 동기화. 몸웅크림/몸돌림 자세분리, 역돌진이동 프레임독립, 점프궤적과시간동기화. 승인물고기원본아트 미변경.

## 검증
Godot4.4.1 import/문법 정상, 신규 action_readability + 기존25개 회귀검사 통과. 어종/별/등급 조합12000선택검사, 전조→행동전환, 착수창분리, 오입력/정답텐션비교,3초손떼기생존, 색변화 검사. 초기 신규검사에서 전투상태초기화 누락 발생 후 테스트setup수정, 재실행통과(게임문제아님).
화면10장 생성; 줄85%, 전조, 점프 렌더확인. 초기캡처는 테스트에서배경표시누락, setup수정 후 재촬영. Xvfb기본소켓실패를 TCP동일프로세스그룹으로해결. [위험색 캡처](line_85.png). 재현 tests/action_readability_preview.gd.
실제휴대폰 터치감/전어종 승률 및 고정탭 봇 비교는 미확인. 장시간행동+높은텐션의 체감난도는 추가실기피드백 필요. 경제시뮬레이션은 성공률/투척시간고정이므로 이번액션반영후에도50~90일달성 주장은 하지않는다.
기존 사용자세이브와 분리된 XDG_DATA_HOME, 개발프리뷰 사용. 저장스키마/확률/해금비/미끼/아트원본 변경없음.
