# 헤드랜턴 국소 빛 레이어

사용자는 배우 자체 밝기 일괄 증가를 요청하지 않았다. 그 구현은 정정 대상이다. 기존 헬멧 광원 위치를 유지하되 빛 레이어가 주변과 캐릭터를 함께 밝히도록 구현. 배우 기본 야간 틴트는 일괄 상향 이전으로 되돌린다. 원본 얼굴·몸 PNG와 같은 변환/알파를 사용한 거리 감쇠 가산 조명, 앞쪽 부드러운 광원 번짐으로 눈에 보이는 효과를 만든다.

현재 구현 완료. 배우 기본 야간 틴트 원복, 원본 캐릭터를 투명 마스크에 동일 순서로 합성해 부분 조명. 머리 광원에서 거리감쇠하며 주변 번짐을 별도 전경 레이어로 추가. 낮에는 레이어·마스크 렌더 완전 비활성. 관련6검사 통과; 최종 실제 화면 비교 및 전체 CI 대기. work/*만 저장하고 새 배포 없음.
