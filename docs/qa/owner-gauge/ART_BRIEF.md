# 지역 주인 게이지 — 제작 명세

사용자 2026-10-22 요청: PixelLab에서 각 낚시터 주인의 확정 컨셉/디자인을 참조해 서로 다른 게이지 UI를 제작한다. 현재 연결 도구/인증 없음, 플러그인 검색도 결과 없음. **신규 PixelLab 생성은 실행하지 않았다.** 아래는 제작 준비와 교체 인터페이스이며 완성 아트가 아니다.

## 기능과 공간
- Godot 논리화면270px. HUD 게이지 영역: x8, y=top_y+73, w254, h31. 주인 이미지34×21 영역에 원본 비율을 유지해 넣고 경계 밖으로 내보내지 않는다.
- 텍스트: 지역 주인 이름과 정수 진행률. 이름/숫자는 엔진에서 그리며 생성 이미지에 넣지 않는다. 진행바는 별도 마스크/채움으로0~100%를 정확하게 표현한다.
- 게이지틀/빈트랙/채움은 분리 가능한 구조. 테두리 바깥 장식은 기존HUD/훅바와 겹치지 않게 위 영역 안으로 제한. nearest 픽셀 필터를 유지한다.
- 100% 조우확정 후 경고는3초. 주인명/지역명은 엔진에서 렌더한다. 외부장식이 읽기/전투시야를 방해하면 축소한다.

## 참조와 지역
- 저수지: 실제 승인 청룡잉어(l0_19 원본). 물고기 비늘·지느러미·꼬리의 실제 형태와 색을 확인한 뒤 틀 디자인에 반영한다. 현재 임시 팔레트는 청록/짙은 물색이며 최종색 승인으로 간주하지 않는다.
- 계곡: game/art/fish/l1_19.png 배후의 산천어 승인 원본. game/data/valley/fish_catalog.json의 해당종 컨셉과 원본 형태/무늬를 먼저 확인한다. 임의로 청룡/용형으로 통일하지 않는다. 현재 임시 팔레트 민트/짙은 물색은 최종아트가 아니다.
- 타일바다/균열해역/심해/우주바다: 지역 컨셉은 GAME_BIBLE에 있으나 주인 확정 원본/명세가 없으므로 주인 외형을 새로 만들거나 임의 결정하지 않는다. 해당 원본 확정 후 같은 인터페이스로 제작한다.

## PixelLab 실행 시
1. 접근이 가능해지면 기존 아트 지침을 확인한다. 원본을 직접 보고 실제 형태/색/참조 역할과 해시를 기록한다.
2. 저수지1장 먼저. 글자/숫자/게이지 진행률을 그림에 생성하지 않는다. 배경 투명, 또렷한 픽셀, 기존UI와 같은 그림자/테두리 밀도.
3. 원본크기 및 정수배 확대에서 잘림/색/윤곽/투명도를 검수한다. 통과 후 계곡으로 이동한다. 동시요청 최대1개, 부적합 후 자동재시도/후속호출 금지.
4. 실제 모델·설정·seed·전송참조/결과 해시·작업ID·차감·검수결과 보존. 생성완료와 품질통과를 구분한다.
5. 최종틀/채움을 owner_gauge_ui.gd에 교체하고0/73/100%·경고·짧은화면을 다시 확인한다. 현재 기존 물고기그림/코드틀을 PixelLab 신규생성 결과로 설명하지 않는다.
