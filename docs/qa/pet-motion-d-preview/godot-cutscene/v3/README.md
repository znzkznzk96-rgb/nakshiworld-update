# 낚시월드 · 펫 뽑기 컷신

독립 실행형 Godot 4 프로토타입. `project.godot`을 열어 F6 대신 F5로 실행하면 SSS를 바로 볼 수 있다. 1~7번 키는 D~SSS, 스페이스는 현재 등급 재생이다. 데모는 공통 붕어와 해룡의 기존 PNG를 사용한다. 달·구름·해안·수중 암벽 배경과 금장 엠블럼으로 SSS 검토 시안을 구성했다. 신규 PixelLab 생성은 0건이다.

## SSS 7초 타임라인

| 시간 | 화면 | 구현 |
|---|---|---|
| 0.0–0.8초 | 달빛 아래 어두운 실루엣과 첫 심박 | 동일 배경 위 수면과 카메라를 움직임 |
| 0.8–2.2초 | 심박이 1→3Hz, 균열이 넓어지고 줌이 1.09배까지 접근 | 가속 Tween, 심박 함수로 진동·빛·비네트 제어 |
| 2.2–3.0초 | 짧은 반전과 암전, 수중의 금빛이 오로라로 열림 | 0.095초 반전, 0.65초 명암 전환, 해룡 공개 전 수면 돌파 80ms 정지 |
| 3.0–4.2초 | 붕어가 물을 뚫고 올라와 몸을 틀고, 시점이 1.16배로 붙음 | 카메라·스프라이트 Tween, 첫 파편 |
| 4.2–5.1초 | 정점 슬로우와 충격파 뒤 0.16초 빛 응축. 응축이 풀리며 해룡 공개 | 0.42배 슬로우 0.72초, 국소 섬광과 고리 |

| 5.4–7.0초 | 금장 엠블럼이 박힌 뒤 해룡이 짧게 체공 | AnimationPlayer 1.30→0.91→1.00, 3개 회전 고리와 10개 빛살 |

D~SS의 기존 시간은 유지한다. 270×480 논리 화면과 nearest 필터를 공통으로 사용한다. 기존 배경·붕어·해룡 스프라이트를 사용하므로 원본 도트 크기의 완전한 통일은 최종 에셋 제작 단계에서 작업한다.

심박 코드 예시:

```gdscript
func _heartbeat() -> float:
	var elapsed := _anticipation * 2.25
	var cycle := elapsed + elapsed * elapsed / 2.25
	return pow(maxf(0.0, cos(TAU * cycle)), 5.0)
```

프레임 수는 에셋 가이드다. 전체 컷신은 Godot에서 60fps 렌더하고, 본체 도트는 필요한 길이로 포즈를 유지한다. 포즈 사이를 광학 보간하지 않는다. PixelLab 결과는 원본 크기에서 형태와 투명 가장자리를 확인하고, 정수 배율이나 nearest로 표시한다. 40% 구도를 맞출 때는 투명 패딩까지 포함한 캔버스가 아니라 실제 보이는 물고기 외곽을 기준으로 잡는다.

## 붙이는 방법

```gdscript
var shot = preload("res://GachaCutscene.tscn").instantiate()
add_child(shot)
shot.finished.connect(_show_result)
shot.play("SSS", pet_texture)
```

`grade`는 이미 결정된 뽑기 결과를 전달한다. 컷신에는 추첨, 재화 소비, 저장 책임이 없다. `finished` 이후 결과가 화면에 남는다. 닫을 때 `cancel()`이나 `queue_free()`를 호출하면 시간 배율과 이전 카메라를 복구한다. `Tween`은 지속 시간과 공간 이동, `AnimationPlayer`는 임팩트와 배너 박힘을 담당한다. 전역 `Engine.time_scale`은 SSS 정점 720ms 구간에서만 사용하므로 실제 게임 연결 시 컷신 동안 월드 입력을 잠그고, 다른 기능과 시간 배율 제어가 겹치면 공통 시간 관리자에서 이를 소유하도록 연결한다. `reduced_flashes`와 `reduced_motion`은 각각 플래시 및 카메라 흔들림 완화 옵션이다.
