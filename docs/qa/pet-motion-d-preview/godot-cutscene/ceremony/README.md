# 낚시월드 SSS 의식 컷신

Godot 독립 검토판. 프로젝트를 열고 F5. 1~7로 등급 변경, 스페이스로 다시 재생한다. 스프라이트 확대 대신 화면 중앙의 캐릭터를 작게 그렸고, 확보한 여백에 세 겹 마법진과 빛기둥을 배치했다.

| 구간 | 연출 |
|---|---|
| 0.0–2.2초 | 검은 바다에 불씨 22개가 모이고, 수면 균열과 카메라 박자가 빨라진다. |
| 2.2–4.2초 | 황금 제단으로 전환되고 마법진이 열린다. 수면 돌파 순간 80ms 정지, 이어 붕어가 상승한다. |
| 4.2–5.5초 | 붕어가 공중에서 0.42배로 느리게 몸을 튼다. 빛 응축 뒤 양쪽에 네 기둥이 점화되고 스파크·국소 플래시·충격파 뒤 해룡을 공개한다. 엠블럼이 한 박자 늦게 박힌다. |
| 5.5–7.0초 | 해룡은 작은 체공 동작을 하고 마법진 조각, 왕관 아우라와 파티클이 계속 돈다. |

## PixelLab 파츠 제작표

화면은 270×480 논리 픽셀. 캐릭터는 투명 96×96 안에서 실제 실루엣 폭 60~78px을 목표로 하고 SSS 기본 배율은 1배다. 캐릭터, 불꽃, 기둥, 마법진, 배너는 별도 파츠로 제작한다. 배경도 논리 화면에서 채택할 도트 밀도로 작업하고 피사체 중앙 영역의 색 대비를 낮춘다.

| 파츠 | 규격과 제작 방향 |
|---|---|
| 황금 붕어 | 투명 96×96. 기존 외형을 키 이미지로 둔다. 상승 6~8포즈, 몸 틀기 6~8포즈. 호박 갈색 그림자, 꿀빛 몸통, 아이보리 하이라이트. 광택은 윗지느러미에 단단한 몇 픽셀. |
| 해룡 | 투명 96×96, 등장 6~8포즈, 체공 6포즈. 확정 눈·뿔·색 유지. 남청 그림자, 청록 몸통, 민트 하이라이트. 중심과 얼굴 방향 고정. |
| 제단 배경 | 270×480 목표. 밤바다와 제단의 수평선·카메라 동일. 제단 프레임과 반사는 내장하되, 움직이는 빛기둥과 마법진은 분리. |
| 기둥 / 마법진 | 기둥 코어 16×160과 받침 32×20을 분리. 링은 192×192에서 1px, 2px 선과 눈금을 분리. 에지에만 샴페인 금색. |
| 스파크 / 물보라 | 스파크 16×16, 발광 3~5장. 물보라 96×48, 돌파 6~8장. 불씨, 물방울, 충격파는 독립 재생. |
| SSS 엠블럼 | 204×78 투명. 본체·날개·마름모·광택 분리. 글자는 외부 레이블로 유지. |

공통 프롬프트: “Native hard 1px grid, crisp stepped clusters, fixed upper-left light, consistent black-blue shadow and champagne highlight. Transparent for isolated assets. No baked bloom, text, aura, or motion blur.” 실제 게임과 동일한 배율로 검수하고, 명암은 넓은 덩어리에서 가장자리의 밝은 몇 픽셀로 단계적으로 올린다.

## Godot 구현

Node2D 배경 → 가산광 의식 레이어 → 캐릭터 → 화면 왜곡 셰이더 → 엠블럼 CanvasLayer 순서다. 카메라와 위치는 Tween, 국소 플래시와 착인은 AnimationPlayer가 담당한다. 2D 정수 기본 배율, nearest, transform snap을 사용한다. 카메라 확대나 회전 중 샘플링 때문에 도트 폭의 순간 변화는 가능하다.

```gdscript
fish.scale = Vector2.ONE * (1.0 if grade == "SSS" else 3.0)
fish.z_index = 1
if grade == "SSS":
	_draw_ceremony()
```

고도 카메라 줌 및 화면 왜곡은 프로토타입 장면 안에서만 시연한다. 7초 무음 공유 영상은 Godot 실행 상태를 별도 렌더러에서 재구성했다. 기존 스프라이트와 배경 원본을 재사용했고 PixelLab 신규 호출 0회. 본 게임 미적용.
