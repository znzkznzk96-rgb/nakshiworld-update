# SSS 황금 무대 각성

Godot 4 독립 시연. 프로젝트를 열고 F5를 누르면 SSS 해룡 버전이 실행된다. 1~7로 등급을 선택하고 스페이스로 다시 재생한다. SSS만 황금 무대에 진입한다. 게임 뽑기 결과나 결제 로직과 연결되지 않은 검토용 프로젝트다.

| 시간 | 화면 |
|---|---|
| 0.0–2.2초 | 밤바다에서 실루엣 상승, 수면 균열과 심박 진동이 가속 |
| 2.2–3.0초 | 반전·암전을 지나 일식과 황금 무대로 전환. 좌우 네 기둥이 켜짐 |
| 3.0–4.2초 | 물 위로 돌파한 붕어가 80ms 정지한 뒤 상승. 카메라가 1.16배까지 접근 |
| 4.2–5.15초 | 국소 섬광과 충격파, 0.42배 슬로우. 이어 0.23초 동안 빛 응축 |
| 5.15–5.42초 | 해룡 등장. 금빛 파편이 퍼지고 왕관 외곽·고리·광선이 켜짐 |
| 5.42–7.0초 | 금장 SSS 엠블럼이 별도로 박히며 양옆으로 스파크. 해룡은 공중에 떠서 여운 |

## 구현

- Tween은 카메라 접근, 붕어 상승, 무대 크로스페이드와 체공을 제어한다. 전조는 화면을 덮는 밝은 플래시 대신 실루엣·균열·비네트를 쓴다.
- AnimationPlayer의 impact는 정점 및 공개 순간의 플래시·충격파를 제어한다. badge는 1.30 → 0.91 → 1.00으로 크기를 바꾼다. 엠블럼 타격 스파크는 따로 생긴다.
- CanvasItem 셰이더는 화면 텍스처를 한 번 샘플링하여 충격파 주변을 굴절시키고 중심에만 섬광을 합성한다. 표정과 픽셀 외곽이 읽히도록 이펙트 밝기를 제한한다.
- 무대는 평상시 배경과 SSS 배경 2장, 가산광은 크기가 작은 사각 픽셀과 선으로 구성한다. 270×480 기준, nearest. 파편 52개는 위치를 직접 그린다.
- 영상은 Godot 헤드리스 실행 상태를 별도 렌더러에서 재구성한 무음 시연이며, Godot GPU 직접 캡처는 아니다.

```gdscript
# 실제 공개 큐. 호출부의 취소 검사와 타이밍은 GachaCutscene.gd 참고.
_charge = 1.0
await _hold(0.23)
if not _is_current(run): return
_charge = 0.0
_burst = 0.0
_reveal_glow = 1.0
animator.play("impact")
```

이펙트와 아트는 시안이다. 해룡·붕어·엠블럼은 기존 에셋을 사용했고 PixelLab 신규 생성은 0회다.
