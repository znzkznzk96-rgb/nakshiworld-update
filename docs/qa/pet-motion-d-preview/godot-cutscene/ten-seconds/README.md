# SSS 펫 뽑기 10초

Godot 독립 데모. F5 실행, 1~7번으로 등급 변경, 스페이스로 재생. SSS 전용 타임라인이다.

| 시각 | 연출 및 타이밍 |
|---|---|
| 0.00–0.92 | 입질. 0.18초 동안 1.045배로 툭 당긴 뒤, 0.22초 되돌림과 짧은 줄 풀림. 첫 타격은 작은 물결과 미세 진동으로 표현한다. |
| 0.92–3.82 | 다시 팽팽. 전조 강도 0.09→1.0을 SINE IN_OUT, 실루엣 가속은 CUBIC IN, 줌 1.00→1.09는 QUAD IN. 수면 균열과 불씨의 수렴을 같은 강도 값으로 제어한다. |
| 3.82–5.05 | 0.095초 짧은 반전, 1.05초 암전·황금 무대 전환. 수면 돌파 포즈를 실제 시간 80ms 유지한다. |
| 5.05–6.65 | 붕어 상승 CUBIC OUT, 카메라 1.16배. 삼중 마법진과 기둥이 화면 외곽을 채운다. |
| 6.65–7.75 | 정점 슬로우 0.42배·약 0.86초, 이어 약 0.23초 빛 응축. 해룡 공개 때 빛기둥·충격파·금빛 파편이 다시 터진다. |
| 7.75–8.18 | 해룡 공개를 먼저 읽힌다. 약 0.43초 뒤 SSS 엠블럼이 별도 타격으로 박힌다. |
| 8.18–10.0 | 두 번의 작아지는 SINE 체공, 회전하는 삼중 링·왕관 빛과 스파크 여운. |

## 트랙과 재생 제어

- 기존 배경 → 마법진·빛기둥 → 캐릭터 → 화면 왜곡/플래시 → CanvasLayer 엠블럼 순서를 유지한다. 스프라이트와 UI는 nearest이며 SSS 붕어·해룡 기본 배율은 1배다.
- Tween은 카메라·긴장 수치·체공을 담당한다. AnimationPlayer의 impact는 플래시·충격파를, badge는 1.30→0.91→1.00 착인을 재생한다. 등급 배너와 파편 타격 상태는 해룡 공개와 0.43초 분리한다.
- 시간 배율을 바꾸는 구간의 대기는 실제 시간으로 카운트한다. 취소나 종료 시 기존 배율과 카메라를 복구한다. 반복 재생 시 이전 코루틴은 실행 토큰을 검증하고 중단한다.
- 기존 붕어·해룡 96×96을 재사용한다. 링 192×192, 스파크 16×16은 교체 가능한 파츠 규격이다. 독립 검토판에서 이 두 역할은 기존 Godot 도형 이펙트를 사용한다. 추가 PixelLab 호출은 0회.
- 공유 영상은 Godot 시퀀스 상태를 별도 렌더러에 넘겨 구성한 무음 검토본이다. 본 게임 미적용.
