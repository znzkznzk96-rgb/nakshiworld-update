# 낚시월드 · 펫 뽑기 컷신

독립 실행형 Godot 4 프로토타입. `project.godot`을 열어 F6 대신 F5로 실행하면 SSS를 바로 볼 수 있다. 1~7번 키는 D~SSS, 스페이스는 현재 등급 재생이다. 데모는 공통 붕어와 해룡의 기존 PNG를 사용한다. 배경과 이펙트는 임시 도형 렌더이며 신규 PixelLab 생성은 0건이다.

## 등급별 구성

| 등급 | 물고기와 불꽃 | 박자 |
|---|---|---|
| D | 은회색, 작은 물방울 5개 | 짧은 물결, 금방 공개 |
| C | 청록 부채꼴 8개 | 수면 빛이 먼저 올라옴 |
| B | 파란 오각 별 14개 | 좀 더 긴 실루엣 상승 |
| A | 보라색 양쪽 폭죽 18개 | 좌우에서 공개점으로 시선 유도 |
| S | 주황 꽃 24개와 충격파 | 정점에서 빛이 한 번 터짐 |
| SS | 은백 이중 고리 33개 | 긴 전조와 두 겹 파장 |
| SSS | 금백색 52개, 오로라와 충격파 | 상승, 반전·암전, 돌파 히트스톱, 공중 슬로우, 체공 배너 |

SSS의 실루엣이 수면 밑에서 약 1초 동안 올라오며, 균열이 옆으로 번진다. 반전 65ms 뒤 암전과 오로라 전환을 약 360ms로 연결한다. 수면 돌파 포즈를 실제 시간 80ms 유지하고, 카메라를 당겨 1.16배 줌과 흔들림을 준다. 정점에서 황금 플래시와 화면 샘플링 충격파를 시작하고, 몸을 느리게 틀며 실제 시간 380ms 동안 재생 속도를 0.42배로 낮춘다. 펫으로 전환한 뒤 아우라 안에서 떠 있는 상태로 SSS 배너를 찍는다. 캐릭터는 수면으로 떨어지지 않는다.

## PixelLab 제작 목록

| 에셋 | 원본 규격과 프레임 | 필요한 상태 |
|---|---|---|
| 공통 붕어 | 96×96에서 예비 24~32장, 투명 | 실루엣용 기준 포즈 1장, 수면 돌파 6~8장, 상승/몸 틀기 8~12장, 공중 안착 4~6장. 바탕 스프라이트와 그림자 마스크 분리 |
| 펫별 공개 | 96×96, 12~20장, 투명 | 시작 실루엣 1장, 펼쳐지는 등장 6~10장, 공중 안착 3~5장, 호버 루프 4~6장. 기존 픽셀랩 펫을 키 이미지로 사용 |
| 수면 균열 | 160×48, 8~12장 | 작은 중심 빛에서 가지가 퍼지고 잦아듦 |
| 물기둥 | 128×192, 12~16장 | 솟아오름, 왕관처럼 펼침, 물방울 분리 |
| 물보라·물결 | 160×60, 8~12장 | 돌파와 수면 반사에 필요한 거품과 물방울 |
| 충격파 링 | 128×128, 6~8장 | 발광 링의 테두리. 화면 왜곡은 Godot 셰이더에서 처리 |
| 폭죽 스파크 | 16×16 또는 24×24, 4~6장 | 불씨, 순간 점화, 파편, 소멸을 분리. 패턴과 등급 팔레트는 Godot에서 제어 |
| 오로라·아우라 | 띠 128×64, 루프 8~12장 | 뒤쪽 오로라, 펫 앞뒤를 도는 별, 황금색 하이라이트 |
| 배너 | 청동 플레이트 160×48 및 장식 레이어 | 등급 글자는 Godot Label. 기본 프레임 1장, SSS 좌우 금장과 스파크 레이어 분리 |

프레임 수는 에셋 가이드다. 전체 컷신은 Godot에서 60fps 렌더하고, 본체 도트는 필요한 길이로 포즈를 유지한다. 포즈 사이를 광학 보간하지 않는다. PixelLab 결과는 원본 크기에서 형태와 투명 가장자리를 확인하고, 정수 배율이나 nearest로 표시한다. 40% 구도를 맞출 때는 투명 패딩까지 포함한 캔버스가 아니라 실제 보이는 물고기 외곽을 기준으로 잡는다.

## 붙이는 방법

```gdscript
var shot = preload("res://GachaCutscene.tscn").instantiate()
add_child(shot)
shot.finished.connect(_show_result)
shot.play("SSS", pet_texture)
```

`grade`는 이미 결정된 뽑기 결과를 전달한다. 컷신에는 추첨, 재화 소비, 저장 책임이 없다. `finished` 이후 결과가 화면에 남는다. 닫을 때 `cancel()`이나 `queue_free()`를 호출하면 시간 배율과 이전 카메라를 복구한다. `Tween`은 지속 시간과 공간 이동, `AnimationPlayer`는 임팩트와 배너 박힘을 담당한다. 전역 `Engine.time_scale`은 SSS 정점 380ms 구간에서만 사용하므로 실제 게임 연결 시 컷신 동안 월드 입력을 잠그고, 다른 기능과 시간 배율 제어가 겹치면 공통 시간 관리자에서 이를 소유하도록 연결한다. `reduced_flashes`와 `reduced_motion`은 각각 플래시 및 카메라 흔들림 완화 옵션이다.
