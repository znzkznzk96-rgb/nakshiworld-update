# 회관·대장간 시안 불일치 정정

2026-11-10 사용자 휴대폰 화면과 함께 v1.19 회관·대장간이 승인 시안과 다르다고 거절했다. 공개·기능 검사 성공은 미술 품질 승인과 별개다.

원인: 승인 시안의 명암·재질·시설 아이콘을 실제 아트로 제작하지 않고 shop_restyle.gd의 단순 도형으로 대체했다. forge_layout.gd는 기존 32×32 낚싯대 이미지를 크게 확대했다. 기술적 불가나 설치 오류가 아닌 구현·검수 판단 오류다. 기존 기록의 ‘승인회관/대장간’ 표현은 선택된 콘셉트를 뜻하며 실제 구현의 사용자 승인을 뜻하지 않는다. 현재 구현은 사용자 거절 상태다.

다음: 기존 선택 시안은 유지하고 실제 아트 제작 범위와 PixelLab 기존 연결을 확인한다. 나무 프레임·시설 아이콘·장비 전시의 명암/디테일을 재현하고 실제 Godot 화면으로 비교한다. 글자·수치·가격·클릭 판정은 게임 데이터와 분리한다. 유료 생성은 기존 단일요청·첫 결과 검수·불합격 중단 규칙을 따른다. 이번 정정 기록 시점 새 유료 생성 0, 수정 구현 0, 추가 배포 0. v1.19 공개 사실과 해시는 보존하며, 이전 배포 승인을 다음 패치에 재사용하지 않는다.
