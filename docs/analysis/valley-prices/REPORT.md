## 비교 모형과 한계
compare.py는6개 파츠/어장조건에 각100만 개체를 생성하고 미끼2조건을 비교한다. 현재 별 가중치·어장 감소·별 내부 균등 어종·개체등급 가중치·계곡 종별 길이분포를 사용한다. 모든 찌 판정GREAT(등급승강 없음), 강화0, 모두 포획성공한 조건부 가격 모형이다. 전투/실패/왕복/손질/수족관/오프라인/시간당 수입·지역해금 일수는 계산하지 않는다. 전체 진행 시뮬 통과로 해석하면 안 된다. 주인 빈도는 미정이라 일반어종 평균에서 제외한다.

## 비용·보상 연결
- 현재 계곡 파츠는 해당 지역 해금비3300의5/10/18/30%를10단위 반올림하여170/330/590/990, 총2080비늘. 다음 낚시터 해금비52000비늘. 저수지 파츠165/330/594/990과 구분.
- 균형안에서 계곡 서브6종(버들치/나뭇잎꼬리/물방울송사리/조약돌고기/구름피라미/하늘연어)을 노멀·평균크기·강화0으로 기증하면 판매가합1130, 보상1356비늘+30혼. 실제 지급액은 제출개체 등급·크기·저장된 판매가에 따라 변한다.
- 주인 균형 기본20000 → 노멀평균 기증30000비늘+2진주, 신화평균 기증90000비늘+2진주. 후자는 다음지역 해금비52000을 넘는다. 라이선스 조건은 별도지만 돈 관문이 크게 완화된다. 주인 등장주기를 정하지 않고 진행일수를 단정할 수 없다.
- 갯지렁이60을 쓰면 균형안의 동일조건 평균 판매234.5에서 미끼1개 차감174.5비늘. 지렁이 차감217.6보다 적다. 고급등급 수집 가치/전투성공률과 미끼 경제는 별도 검토 대상이며 이번에 값을 변경하지 않는다.
