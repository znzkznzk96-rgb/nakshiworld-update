## 2. 기획안의 확정 수치 (아직 코드에 없는 것 포함) [기획안]

### 2-1. 등급

| 등급 | 최종 목표 분포 (보통 실력, 지렁이) | 비늘 배수 | 진주 |
| --- | --- | --- | --- |
| 노멀 | 70% | ×1 | 0 |
| 레어 | 22% | ×1.3 | 0 |
| 유니크 | 6.5% | ×1.7 | 0 |
| 전설 | 1.3% | ×2.2 | 1 |
| 신화 | 0.2% | ×3 | 5 |

PERFECT 20% → +1, MISS −1을 거친 결과가 위 분포다(확정 2026-10-17). 숙련은 69.2 / 22.6 / 6.4 / 1.55 / 0.22%, 초보는 72.6 / 19.7 / 6.5 / 1.05 / 0.18%.

### 2-2. 파이팅·장비

- 낚싯대 6단계(대나무 ~ 은하): 텐션 속도 ×1.00 → ×0.60 (단계당 −0.08), 감는 힘 ×1.00 → ×1.60 (단계당 +0.12). **확정 표**
- 줄: 단계마다 돌진 충격 −10% (최대 −50%). **확정**. 줄 값 = 그 낚시터 해금비의 100%. **확정 (2차)**. 파츠 체계로 바뀌며 "줄" 파츠에 합쳐짐
- 낚시터 배수: 물고기 힘·돌진 충격 × (1 + 0.15 × 낚시터 단계). **확정**
- 점프: 공중에서 감고 있으면 0.25초 뒤부터 텐션 초당 +90. 착수 0.4초 안 탭 = 거리 +12. **확정**
- 잠수: 출현 8% + 등급당 2%, 힘 2배, 감고 있으면 충격의 60%. **시제품 반영**
- 성격: 기세 = (등급 + 0.2 + 0.6 × 성격) ÷ 4.8, 돌진마다 ±15%. **시제품 반영**
- 등급별 몸짓 표(혼란도, 돌진 25~45%, 예고 0.70~0.40초, 급당김 주기, 역돌진 12%, 분신 10%)는 기획안 "★·등급별 차이".

### 2-3. 미끼 (등급 배수)

맨바늘 무료 ×0.85 / 지렁이 10 ×1.0 / 갯지렁이 60 ×1.25 / 새우 300 ×1.5 / 오징어 1,200 ×1.8 / 황금 루어 3,000 ×2.1 / 전설의 미끼 6,000 ×2.5 (비늘, 1회). 표는 기획안에 있고 확정 표시는 없다.

### 2-4. 해금비 (비늘)

| 낚시터 | 해금비 | 상태 |
| --- | --- | --- |
| 계곡 | 3,300 | 튜닝값 |
| 방파제 | 5.2만 | 튜닝값 |
| 선상 | 103만 | 튜닝값 |
| 심해 | 670만 | 튜닝값 |
| 우주 | 2,830만 → ×1.3 ≈ 3,680만 (3차 확정) → 약 7,360만 (강화 하락 없음 제안 기준) | **충돌 C11** |

조건: 이전 낚시터 도감 60% + 그 낚시터 주인 + 비늘. "주인 잡기로 확정할지"는 남은 결정이다.

### 2-5. 주인 (★5)

- 기척 게이지(던지기 횟수): 저수지 100 / 계곡 150 / 방파제 250 / 선상 350 / 심해 400 / 우주 500. **시뮬레이션 값**
- 놓치면 게이지 80% 유지. **결정 2026-10-18**
- 주인 등급 중 신화 확률: 저수지 12% → 계곡 10 → 방파제 8 → 선상 6 → 심해 5 → 우주 4%. **임시**
- 미끼 레시피 재료 (낚시터별, **임시**): 저수지 ★2 레어 2 + ★3 1 / 계곡 ★3 레어 1 + ★2 유니크 1 / 방파제 ★3 레어 2 + ★2 유니크 1 / 선상 ★3 레어 2 + ★2 전설 1 / 심해 ★3 유니크 1 + ★2 전설 1 / 우주 ★3 유니크 1 + ★2 전설 2 + ★4 1.

### 2-6. 수족관·마을

- 관람객 상한(마을 Lv.1~7): 10 / 40 / 90 / 520 / 2,900 / 15,600 / 58,000 비늘/분. **시뮬레이션 값**
- 수조 확장(옛 표): 4칸 1,000 / 5칸 5,000 + 도감 25% / 6칸 20,000 + 마을 Lv.2.
- 마을 레벨(옛 표): Lv.2 3,000 + 도감 30% + ★3 1마리, Lv.3 15,000 + 도감 60% + ★4 1마리. 4차 확정의 관람객 상한과 함께 정리 필요(충돌 C10).

### 2-7. 강화 (**미확정**)

- 낚싯대별 최대 단계: 대나무 +5, 카본 +8, 원투 +10, 선상 +13, 심해 +16, 은하 +20. (예시)
- 혼 = 낚싯대 계수 [1, 2, 4, 8, 16, 32] × 목표 단계 × 5 (초안). 계수는 원래값으로 복구 결정(2026-10-18). 단계마다 1.2배씩 느는 방안도 결정 목록에 있다.
- 시뮬레이션용 규칙: 비용 3,000 × 지역 배수 × 1.3^단계, 성공률 95%에서 단계마다 −5%(최저 30%), +5 이상 실패 시 −1, 단계당 판매가 +5%.
- 제안: 실패 시 하락 없음(운 차이 감소). 확정 전.

### 2-8. 진주

얻는 곳: 일일 미션 10/일, 새 종 5, 도감 등급 칸 2, 전설 1·신화 5, 진주조개(바다, 던질 때 1.5%) 1~3. 쓰는 곳: 강화 보호권 15, 수족관 장식 50~300, 의상 400~1,500. 하루 양은 기획안 안에서 40개와 60개가 섞여 있다(충돌 C9).

## 3. 시뮬레이션 결과 요약 [기획안]

| 시뮬레이션 | 핵심 결과 |
| --- | --- |
| 봇 4종 × 낚싯대 × ★ × 등급 | 돌진 충격을 넣기 전에는 몸짓을 무시하고 게이지만 봐도 성공률이 같았다 → 충격 도입. 예고 0.2~0.25초는 읽을 수 없음 → 최소 0.4초 |
| 별 찌 판정 | PERFECT가 너무 쉬움(보통 노멀 96%) → "PERFECT = 20% 확률 +1"로 확정 |
| 줄 효과 | 초보·보통을 크게 돕고 숙련에겐 작음 |
| 낚시터 배수 | 배수가 없으면 뒤로 갈수록 쉬워짐 → 1 + 0.15 × 단계 |
| 300일 경제 (최종, 강화 하락 없음 가정) | 우주 해금: 하루 30분 보통 61일(57~71), 숙련 58일, 초보 71일. 10분 보통 117일, 2시간 39일, 10시간 30일 |
| 해금 일정 (보통·30분) | 계곡 3.3 / 방파제 7.3 / 선상 16.4 / 심해 29.9 / 우주 60.5일 (목표 2.5 / 7 / 18 / 35 / 65) |
| 운 차이의 원인 | 처음엔 열쇠 물고기 운 → ★5 주인 게이지로 해결. 그다음은 강화 도박(하락) → 하락 없음 제안 |
| 보관통 | 보통·30분: 꿰미 0.5일, 양동이 1.4, 그물망 2.9, 아이스박스 4.3 / 7.2 / 12.9 / 22.1 / 27.9일. 마을 왕복 하루 2.5번 |
| 문제 | 엔드 박스(4,000만)를 우주보다 먼저 삼 → 우주 이후 판매로 잠그는 게 맞음 |
| 도감 600칸 | 300일: 라이트 78%, 보통 87%, 헤비 95% |
| 어장 채우기 | 하루 10시간 플레이어만 씀 → 삭제 확정 |

주의: 봇은 실수·집중력 저하가 없어서 실제 사람 성공률은 더 낮다. 기획안 스스로 "직접 플레이로 확인 필요"라고 적었다. 원인을 확인하지 않은 관찰(헤비 플레이어가 빨라진 이유 등)은 기획안에 "추정"으로 표시돼 있다.
