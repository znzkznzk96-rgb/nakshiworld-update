**결론: 해금비2배는 수족관 수입의 비중을 높이지만, 신규시작→타일바다 준비는 중앙값3일차→4일차 정도다. 수족관이 없어도4일차이므로, 수족관이 해금기간을 확실히 단축한다고 볼 수 없다.**

## 승인과 범위
사용자104000비늘 확정(이전52000유지 대체), 이유는수족관기능을살리는것. 전체클리어50~90일/하루2시간은사용자목표이며이분석으로달성된것이아니다. assistant의타일진입7~10일안은미확정비교목표다.
운영0.75/계곡입장잠금유지. 작업브랜치 미끼5/15/20·고갈확률계산잔량하한70% 반영조건으로 분석. 실제게임해금비코드는아직52000이며104000은결정기록과모형에반영했다. 계곡50/32/14/4는미승인후보로별도비교만한다. 후속지역콘텐츠/해금일수는만들지않았다.

## 수족관이 작동하는 방식과 한계
- 6칸기준비용2배시해금까지오프라인수입중앙값20,014비늘→약78,108비늘. 수족관은실제로돈을벌지만전시개체의즉시판매를포기하는기회비용이있다. 정확한결과는results.json.
- 20칸과주인전시는수족관수입비중을크게높인다. 그렇다고중앙값해금일이더빨라지지는않았다. 전시·확장비용/필수번들/주인포획순서도영향을준다.
- 같은6칸정책에서오프라인수입만제거(어장오프라인회복은유지)하면플레이중앙값6.05→7.63시간. 오프라인수익의도움은있지만모든수족관정책이즉시판매보다유리하다는뜻은아니다.
- 계곡주인노멀평균가16000을전시하면기본방문객기준8시간수입은25600비늘. 기존기증은일회24000비늘+2진주. 여러번접속할수록전시수익이누적되므로장기모형에서주인을단순판매가격만으로평가하면안된다. 실제가격은등급·크기에따라달라진다.
