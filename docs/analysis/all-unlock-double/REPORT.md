# 전체 낚시터 해금비 2배 재시뮬레이션
2026-10-23. 기존 타일만 2배 해석을 사용자 정정으로 대체. 게임 코드/배포 미변경.

## 확정 비용
동네 저수지 0→0, 거꾸로 폭포 계곡 3300→6600, 타일 바다 52000→104000, 균열 해역 1030000→2060000, 심해 6700000→13400000, 우주 바다 28300000→56600000.
후반 가격까지 결정 범위에 포함하되 시뮬레이션은 구현된 첫 두 지역부터 타일 해금 조건/자금 확보까지만. 6지역 완주를 시뮬레이션했다는 뜻이 아님.
