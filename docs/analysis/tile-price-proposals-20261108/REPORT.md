## 해석
- 추천안 자금확보 중앙값: 판매만 충분한어장6.21h/고갈연속16.23h. 수족관+배 실제투자비를 번돈에서 지불하며 병행하면4.56h/9.45h. 15표본 경로의 min~max는 충분어장4.13~5.11h, 연속8.36~10.30h(통계 신뢰구간 아님).
- 현행은 이번수족관투자정책에서21.66h/26.41h. 지난분석102~236h는 판매위주 결과이며 수족관까지포함한수치가아니다. 이전 범위와 혼합하지 않는다.
- 전종10배안은 주인160,000으로 올라가지만 ★1은250~550에 머문다. 연속수익의 주인비중 약81% 유지. 추천안은 주인65,000(+4.06배)·★1 크게상향하여 주인비중 약25%까지 낮춘다(전체매출, 전시선택 전 기준). 충분어장에서는 약12%.
- gentle안은 소극적이라 수족관투자병행해도 고갈시15.64h; balanced안11.34h; active안9.04h. rounded안9.45h로 active와 비슷하면서 가격을 읽기좋게 다듬고 별등급간 구분을 키웠다.

## 실험과 검증
실제 Godot start_wait/길이/주인게이지/미끼/기증보상 함수를 사용해 5시드×3미끼×2어장×6,000회=180,000회 추첨. 같은 추첨열을 6가격표 및 판매/기본수족관/적극투자수족관 정책에 재생해 가격외 난수차이를 없앴다. 기존 Godot 판매가와 Python 재현식18만건 일치(불일치0). seed·가격·요약·180개 후보별 경로결과는 [RESULTS.json](RESULTS.json).
실제 전투/입력/왕복을 재현한 봇 플레이가 아니다. 정상1회30초 + 실제입질대기차/고갈페널티, 포획90%, 챔질MISS0·PERFECT50%×승급20%=10%승급, 지역파츠4개기보유·강화0. 매회어장충분은 무료즉시보충 가정으로 휴식시간0인 낙관적 상한이다. 연속모드는 실제고갈/회복. 초기비늘0·수족관빈3칸·배0, 미끼비용과기증손실반영. 재고미끼는 준비되어있고 사용량당비용차감한다. 장비구매/가방/이동/관리시간·기타선물·원정·로봇 제외. 오프라인소득은 포함하지 않았다.
수족관투자는 현행 실제 확장비9,600·배전체9,980 지출, 수입은 저장가격합×0.15×방문배율/시간. 좋은물고기전시로 판매기회비용반영, 교체시 기존물고기는 회수후판매한다. 관리이동시간0이라 낙관적이며 사용자가 직접 하는 실제운영과 차이난다. 투자정책 자체도 전역최적화한 것은 아니다.
