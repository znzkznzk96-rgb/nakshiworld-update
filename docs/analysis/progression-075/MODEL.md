## 사용자 행동 가정 (게임의 확정 규칙 아님)
- 1투척 기본30초, 소모된 어장/무미끼 입질 지연은 추가. 마을 1회30초. 실제 전투 프레임을 구동하지 않는 경제 모형이다.
- 기본 포획성공률85%, PERFECT30/GREAT60/MISS10%; PERFECT일 때20% 승급, MISS는1등급 하락 후 전투지속. 성공률65/98%, 기본투척20/45초도 별도 비교한다. 별·등급별 실제 성공률이나 모바일 실측값이 아니다.
- 파츠우선 구매(20비늘 여유), 회복2단계(250/700), 어장규모1단계300, 보관통2단계150/800, 카본낚싯대2000, 수족관확장300. 구매가능성 여유금 정책은 코드에 명시. 카본 비용은 반영하되 전투성공률/시간은 외생 고정이라 장비의 전투성능 향상을 별도 재현하지 않는다.
- 강화·손질·배/회관 업그레이드·진주소비 없음. 이들은 필수 해금 조건이 아니다. 강화 선택에 따른 비용/혼 소모/판매가상승까지 포괄한 모든 플레이 전략 최적화가 아니다.
