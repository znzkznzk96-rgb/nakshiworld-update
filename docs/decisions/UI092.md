# UI092 — 미끼 선택·마을 버튼 (2026-10-29)

사용자 시안 수정: 미끼 버튼은 더 작게, 낚시 화면 왼쪽 메뉴 바로 옆. 오른쪽 물고기 조작 영역 확보. 현재 미끼 아이콘·수량, 탭하면 위로 작은 2열 선택창. 기존 6종 미끼/아이콘/효과/가격 유지. 보유 미끼 직접 선택, 빈 바늘 선택 가능. 캐스팅 전 변경, 소진 후 다른 미끼를 자동 소비하지 않음. 시안 문구·수량은 예시이므로 실제 데이터 사용.

마을 우편·가이드: 기존 나무·청동 프레임과 PixelLab 아이콘 계열, 버튼 안은 봉투/책 그림, 이름은 버튼 아래 한 줄. 미읽음 작은 빨간 점. 버튼 크기/간격 통일. 기존 우편/가이드 기능 유지.

사용자 ‘그렇게 수정하고 업데이트및 배포가자’로 위 변경과 PixelLab 제작·검증·공개배포 승인. 기존 승인 PixelLab 아이콘 재사용 가능. 미끼 버튼 프레임 신규 PixelLab 1회 생성 후 검수; 추가 자동재생성 금지. 세이브/재화/낚시·탐험 밸런스 보존.
