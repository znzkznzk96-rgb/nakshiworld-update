## 업데이트 장애와 해결
설치된 0.60 APK의 root.gd는 version.json을 읽고 patch.pck?v=61.0을 요청했다. Worker의 requested !== String(d.code) 검사가 이를 거절하여 기존 0.60으로 시작했다. “받는 중”은 성공 증거가 아니었다.
수정은 정수 또는 소수부가 0인 숫자 문자열만 허용하고 Number(requested)와 manifest code를 비교한다. 61, 61.0, 61.00은 허용하고 60.0, 61.1 등은 거절한다.
GitHub 코드 수정 커밋: 610fc040a6fe7302263a09b5ca771f235e340299.
재발 방지 검사 커밋: c7e29e65fe01e7c3c0840b30d809c403cfd12fad.
Cloudflare 연결의 내부 오류로 AI 직접 배포는 실패했고 사용자가 대시보드에서 수정·배포했다. 이후 사용자 성공 보고와 이번 공개 주소의 다운로드 해시 일치로 동작을 확인했다. 운영 Worker 전체 설정/코드를 인증 API로 재취득한 것은 아니다.

## 최신 구성
엔진 Godot 4.4.1, 안드로이드 세로 화면. 논리 화면 폭 270. 로컬 저장 방식이다.
- root.gd: 업데이트 확인·다운로드·검증·PCK 로드·화면 컨테이너 생성. BUILD_CODE=60은 APK 기본 버전이며 0.61 패치 누락 증거가 아니다.
- main.gd: 낚시 상태, 종/등급·확률, 입력·연출·도감·세이브·버전 표시.
- village.gd: 마을 및 상점 흐름.
- text_layer.gd: 고해상도 글자 계층.
- addons/reservoir/equipment.gd: 장비 보유·장착·탈착·판매·저장 복원.
- inventory.gd: 가방과 목록 UI; enhancement.gd: 강화 확률·비용·연출.
- commerce.gd: 구매 견적·확인; mailbox.gd: 패치 안내 우편과 읽음/삭제 상태.
- aquarium_view.gd, visitors.gd, environment.gd, title_screen.gd: 수족관·주민·환경·타이틀.

## 0.61 범위와 검증 한계
이전 배포 기록은 낚시 UI, 몸짓도감 애니메이션, 장비 인벤토리·장착/탈착·판매, 강화 효과 반영을 설명한다. 실제 관련 모듈과 equipment_verify.gd 테스트가 포함되어 있다. 모든 UI/기능을 이번에 휴대폰으로 직접 조작한 것은 아니다. 사용자의 업데이트 성공은 모든 게임 플레이 기능의 완전한 검증을 뜻하지 않는다.
낚싯대가 없을 때 낚시 차단, 장비 저장/복원, 12개 몸짓 도감 렌더링은 기존 자동 검사에 포함된다. 이번 실행 결과는 VERIFICATION.md 참조.
