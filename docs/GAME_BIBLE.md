## 표현/아트 원칙

- 따뜻하고 아기자기한 16비트 도트, 세로 모바일, 선명한 픽셀 묶음과 제한된 명암.
- 낚시 플레이가 화면 중심. 저수지와 비슷한 플레이 구도(왼쪽 앉는 자리/수면/수중 플레이 공간)는 유지하되 지역 배경과 바닥은 분명히 다르게.
- 계곡 사용자가 선택한 상세 배경을 보존. 캐릭터가 앉을 왼쪽 낚시 자리는 실제 게임에서 낮게 배치하고 너무 길게 만들지 않는다. 배경에 캐릭터/의자/구름/폭포가 구워져 있으면 안 된다. 기존 의자·캐릭터를 재사용한다.
- 구름은 하늘 마스크 내 별도 레이어, 역폭포는 수면에서 위쪽 섬으로 올라가는 별도 애니메이션, 수면은 얕은 잔물결/반사 별도 레이어, 수중 빛도 별도 레이어. 수심색과 지형은 선택한 정적 배경을 보존한다.
- 저수지 건물/바닥/배경을 다른 낚시터에 복사하지 않는다. 배경을 임의 재생성·대체하지 않는다.
- 승인 범위를 벗어난 유료 PixelLab 생성은 진행하지 않는다. 생성 규칙은 `docs/FISH_ART_RULES.md` 우선.

## 유지해야 할 핵심 플레이/경제

- 별(어종 난도)과 개체 등급은 독립. 신화 개체라고 최대 길이를 보장하지 않는다.
- 같은 낚싯대 업그레이드/파츠 체계는 낚싯대 1개 + 찌·바늘·줄·릴 4파츠. 파츠 부족은 가능한 별의 상한을 제한. 별5 주인은 게이지 방식으로만 등장.
- 가방은 무게 용량, 넘치는 큰 물고기 1마리는 어깨에 메고 돌아올 수 있음. 현장 판매 대신 마을에서 판매/전시/손질을 선택.
- 수족관은 오프라인 수익, 기존 사용자 세이브와 업데이트 안전성을 보존.
- 자세한 기존 세부 밸런스는 `docs/REGIONAL_SHOP.md`, 최신 소스·Release 검증은 `docs/RELEASE_068_VERIFICATION.json`을 참고하되 이 문서의 최신 사용자 결정을 우선한다.
