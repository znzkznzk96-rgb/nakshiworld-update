# 컷신 4컷 (초안, 기존 4·5컷을 하나로 합침)
흐름: 1인칭 눈 모양 깜빡임(마을이 도트 덩어리로 흐리다가 딱 선명) → 시선을 내려 물에 잠긴 젖은 발(찰랑) → 팔이 들어와 시계에 "위치 불명" 깜빡 → 검은 암전 → 3인칭: 큰 달 저수지 물가에 앉아 멍한 연구원 → 오솔길에서 낚싯대를 문 흰 고양이만 걸어옴 → 다시 물가로 돌아와 고양이가 들어와 툭 떨어뜨림. 약 12.8초.
- 그림(PixelLab 228회분): 최종 배경은 c4n_e(물속에서 눈높이로 본 호수·마을)·c4n_f(물에 잠긴 발)·c4n_v(연구원 물가)·c4n_p(고양이 오솔길), 진한 달밤 색감으로 다시 뽑음(흐린 3컷 그림을 스타일 기준으로 쓰지 않음). 앞선 c4_e·c4_f·c4_v·c4_p는 폐기본. 연구원 c4_s_0~3, 고양이 c4_cat·c4_catwalk_0~8.
- 고양이 낚싯대는 PIL로 몸과 분리(stick_*/cat_*, 1/3 최근접 축소)해 중간에 떨어뜨릴 수 있게 했고, 모양은 나뭇가지에 가까움.
- 연출: proj/main.gd + mosaic.gdshader(정수 도트 뭉개기) + wave.gdshader(물결). 눈꺼풀·물방울·시계 글자는 코드. 소리는 gen_sfx.py 합성(heart, drop) + 2컷 재사용.
- 녹화: `godot --path proj --write-movie out.avi --fixed-fps 30 --resolution 1080x2400 --quit-after 335` (먼저 `--headless --import`).
