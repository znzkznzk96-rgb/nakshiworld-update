# 컷신 4컷 (초안, 기존 4·5컷을 하나로 합침)
흐름: 1인칭 눈 모양 깜빡임(마을이 도트 덩어리로 흐리다가 딱 선명) → 시선을 내려 물에 잠긴 젖은 발(찰랑) → 팔이 들어와 시계에 "위치 불명" 깜빡 → 검은 암전 → 3인칭: 큰 달 저수지 물가에 앉아 멍한 연구원 → 흰 고양이가 낚싯대를 물고 걸어와 툭 떨어뜨림. 약 10.6초.
- 그림(PixelLab 78회분): source/ c4_v(달 아래 마을 물가), c4_f(1인칭 물가 발), c4_s_0~3(앉은 연구원), c4_cat + c4_catwalk_0~8(고양이 걷기). 처음 3장은 "정책 위반"으로 거부(비용 0), 문장에서 '젖은' 표현을 줄여 다시 요청해 통과.
- 고양이 낚싯대는 PIL로 몸과 분리(stick_*/cat_*, 1/3 최근접 축소)해 중간에 떨어뜨릴 수 있게 했고, 모양은 나뭇가지에 가까움.
- 연출: proj/main.gd + mosaic.gdshader(정수 도트 뭉개기) + wave.gdshader(물결). 눈꺼풀·물방울·시계 글자는 코드. 소리는 gen_sfx.py 합성(heart, drop) + 2컷 재사용.
- 녹화: `godot --path proj --write-movie out.avi --fixed-fps 30 --resolution 1080x2400 --quit-after 335` (먼저 `--headless --import`).
