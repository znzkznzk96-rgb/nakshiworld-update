# 컷신 3컷 (초안)
흐름: 2컷 암전 뒤 타일 바닥이 깨져 빛나는 수면이 됨(차원 열림) → 부츠가 물에 가라앉고 거품·글리치 → 흰빛과 함께 소용돌이 터널 → 낚시월드 저수지(큰 달) 위로 연구원이 떨어짐 → 첨벙·물결 → 암전. 약 9초.
- 그림(PixelLab, 110회분): source/ c3_a1(깨지는 바닥), c3_a2(수면·부츠), c3_b(소용돌이), c3_c(저수지 위에서 본 모습, 4컷 마을 배경으로 재사용 예정), c3_d_0~3(떨어지는 연구원 4프레임).
- 연출: proj/main.gd + wave.gdshader(정수 픽셀 단위 물결·글리치·색 돌림). 빛줄기·바람줄·물결 고리·물방울은 코드로 그림. 소리는 gen_sfx.py로 합성.
- 녹화: `godot --path proj --write-movie out.avi --fixed-fps 30 --resolution 1080x2400 --quit-after 285` (먼저 `--headless --import`).
