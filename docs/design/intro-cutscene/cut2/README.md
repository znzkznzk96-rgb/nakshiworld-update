# 첫 실행 컷신 2컷 (2026-11-27, 사용자 확인 대기)

흐름(사용자 지시로 처음 기획에서 변경): 1컷 복도에서 문이 끼익 열림 → 연구원 "!" "이상현상인가?" → 타일 방(백룸 수영장) 안에서 문 쪽을 본 시점, 연구원이 갸우뚱하고 들어옴 → 문이 쾅 닫히고 어둠 → 형광등이 탕탕 켜짐 → 시계 시점(서서 팔을 들어 봄): TIK 바늘이 점점 빨라져 폭주, 팔이 도트 디더로 사라지고 부츠만 남음 → 타일 틈에서 물이 번져 종아리까지 차오름(화면 흔들림) → 마지막 형광등 불꽃, 암전. 약 15.6초.
- 화면: 360×640 도트를 3배(1080×1920), 위아래 검은 영화 띠. 확대 없음(정수 픽셀 이동만). 연구원 앞모습은 문 크기에 맞춰 정확히 1/2(nearest)로 줄여 씀(타일 방 장면 한정).
- 그림(PixelLab): source/ 에 원본. 앞모습 front_0, 갸우뚱 tilt_0~8, 걷기 walk_0~8(animate-with-text-v3), 열린 문 복도 corridor_open2, 타일 방 room_0, 시계 시점 배경판 plate2_0(사용자 사진 구도 참조), 팔·시계 arm2_0(투명), 물 찬 배경판 water_full(inpaint 2회 이음).
- 연출: proj/main.gd + 셰이더 3개(room·pov·dissolve). 바늘·불꽃·느낌표·문판은 코드로 그림. 실행/녹화: `godot --path proj --write-movie out.avi --fixed-fps 30 --resolution 1080x2400` (먼저 `--headless --import`).
- 소리: gen_sfx.py 합성(끼익·쾅·TIK·타자음·놀람·불꽃·물음), 1컷의 웅웅·점등음 재사용, 물 소리는 game/sfx/refresh65/water.ogg. 글꼴 neodgm.
- PixelLab 사용: 2컷 총 236회분(3121→2885). 쓴 그림 171회분 + 폐기 75회분(바닥에 엎드린 구도 2장, 첫 팔 레이어, 닫힌 문처럼 보인 1차 문). inpaint는 512×512 제한이라 큰 그림은 2회로 나눠야 함(물 찬 배경판 50회분).
- 알려진 한계: 손이 남성스럽다는 의견(미수정, 손만 inpaint 약 10회분), 연구원 앞모습 수첩은 갈색 표지(1컷은 흰 수첩), 걷기 마지막 프레임은 멈춤 자세만 사용. 영상은 용량 때문에 저장소에 넣지 않음.
