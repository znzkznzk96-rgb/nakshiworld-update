## 경계
전투는 화면 전환 검토용 스크립트이며 실제 피해·속성·회복·승률·시간 검증이 아니다. 지원 병사의 포즈가 재생되어도 실제 회복 계산은 없다. 최초 3개 방 완료/15종 보유는 검토용 예시. 새로고침하면 초기화되며 게임 세이브·재화·보상을 수정하지 않는다. 보상, 치료 비용·시간은 준비 중으로 표시한다. 배경 선택과 성공/실패 선택은 검토 페이지의 도구이며 실제 게임 조작이 아니다.

다음 구현: 정식 배경/몬스터 아트, 전체 Godot 프로젝트에서 UI 연결, 개별 병사 전투·치료·보상/저장 규칙 확정 후 적용. 기존 마을 배치는 건드리지 않음. 새 유료 생성 0회.
