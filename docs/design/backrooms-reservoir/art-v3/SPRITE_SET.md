# 어혼 아이템5종 PNG 세트

이 세트는 연성 재료인 물·전기·독·빛·어둠 어혼의 화면 표시용 이미지다.

- 기준 디자인: 최종 1안 ‘꼬리와 지느러미’.
- 물: 사용자가 승인한 재제작 원본을 그대로 사용.
- 나머지4종: 각 속성별 확정 컬러 참조를 사용하여 PixelLab으로1회씩 생성.
- 크기32×32, 투명 배경, 같은 캔버스와 표시 배율.
- game engine에서 최근접(Nearest) 필터 사용, 정수 배율 표시 권장.
- 원본 픽셀 수정/재색칠 없음. 실제 생성 PNG와 참조 PNG를 구분하여 보존.
- all-souls-preview.png: 참조(위)/생성 결과(아래) 비교.
- souls-final-preview.png: 실제 게임용 원본5종 확대 모음.
- REMAINING_QA.md: 각 결과의 제작자 검수.
- *-request.json: 모델 입력·seed·설정.
- all-souls-manifest.json: 파일 해시·크기·투명도.

게임 코드 변경이나 배포 없이 에셋 제작만 수행한다. 물은 사용자 채택 완료, 나머지4종은 제작자 검수 후 사용자에게 제시한다.
