# 나머지 어혼 제작 검수

승인된 물 어혼은 재생성하지 않고 동일 원본을 사용한다. 원본32×32 및 nearest 정수 확대에서 각 결과를 확인한다.

|속성|형태·특징|색·명암|투명·잘림|판정|
|---|---|---|---|---|
|전기|둥근 몸체, 눈, 작은 지느러미, 번개 꼬리 유지|노랑 중간색과 진한 주황 그림자 유지|이진 알파, 여백 확보|제작자 검수 통과|
|독|몸체·눈·지느러미·말린 꼬리 및 방울 유지|연두 몸체와 짙은 초록 그림자 유지|이진 알파, 여백 확보|제작자 검수 통과|
|빛|몸체·눈·지느러미·작은 별 꼬리 유지|크림 몸체와 금색/황토 그림자, 전기와 색 구분|이진 알파, 여백 확보|제작자 검수 통과|
|어둠|몸체·눈·지느러미·말린 연기 꼬리 유지|보라 몸체와 짙은 남보라 그림자, 연보라 꼬리 강조|이진 알파, 여백 확보|제작자 검수 통과|

모든 신규 결과는 원본32×32와10배 확대를 확인했다. 시안과 픽셀 단위로 동일하지는 않으나 공통 몸체와 각 속성색·명암·꼬리 특징을 유지한다. 물은 이전 사용자 승인 파일과 SHA256이 동일하다.

총 유료호출4회, 각1 generation/총4 generation. 자동 재시도0회, 물 재생성0회. 생성/검수 완료이며 게임 적용·배포 없음.
