# 저수지 어혼·병사 첫 제작

어혼은 인벤토리에 보관하고 연성에서 소모하는 재료 아이템이다. 아이콘은 그 아이템의 UI 표시용 이미지다.

## 제작 범위
- 물·전기·독·빛·어둠 어혼: 각 32×32 투명 PNG, 1회씩 생성.
- 기준 병사: 둥근 금빛 붕어와 작은 나무 방패, 48×48 투명 PNG, 1회 생성.
- 사용자 승인 탐험창의 큰 픽셀 묶음, 둥근 몸체, 귀여운 표정에 맞춘다. 시안 이미지는 눈으로 확인하고 텍스트 형태 명세만 사용한다.
- 저수지 기존 물고기 원본의 사실적 비늘 스타일보다 사용자가 지정한 탐험 병사 시안 스타일을 우선한다.
- 아이템은 물 청록 / 전기 노랑 / 독 초록 / 빛 크림 / 어둠 보라로 구분. 색 외에도 형태 차이를 검수한다.
- 병사는 주색 금빛, 보조색 밝은 노랑, 강조색 갈색 방패. 사람 몸통·과도한 갑옷·고해상도 질감 금지.
- 모델 create-image-bitforge, 이미지 참조 없음. 개별 request.json에 실제 입력과 seed 기록.
- 한 번에 유료 호출 한 개. 결과 검수 후 다음 호출. 실패 자동 재생성 없음.

## 적용 상태
제작 시안이며 게임 배포/기존 아트 교체는 하지 않는다. 2·3성 전체 병사 명단은 별도 확정이 필요하므로 무작정 대량 생성하지 않는다.

## 동작 범위
기준 병사 검수 후 방패 공격 4프레임을 1회 생성한다. animate-with-text는 64×64 입력만 지원하므로 48×48 원본을 확대하지 않고 투명 여백으로 64×64에 넣는다. 대기·전진·피격은 원본의 위치 이동으로 표현할 수 있으며 새로운 생김새를 만들지 않는다.
