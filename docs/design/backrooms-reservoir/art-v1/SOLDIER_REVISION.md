# 기준 병사 수정안 — 아직 생성하지 않음

실패 원인 관측: 텍스트 단독 입력에서 물고기·방패·작은 발의 형태 분리가 실패했다. 원인은 확정하지 않으며, 복합 소품 설명이 모델에 혼선을 주었을 가능성이 있다.

다음 요청은 문장을 줄이고 한 개의 몸체와 꼬리·눈·방패 위치를 명시한다. 실패 이미지는 참조에 사용하지 않는다. 재생성1회 추가 비용은 사용자 승인 전 실행하지 않는다.

- 몸체: 가로로 둥근 금빛 타원 한 개.
- 꼬리: 왼쪽 삼각 꼬리 하나.
- 얼굴: 오른쪽 검은 눈 하나.
- 발: 아래에 짧은 갈색 발 두 개.
- 방패: 오른쪽 아래 몸 앞에 작은 갈색 원 하나, 연한 테두리.
- 도트: 검은 외곽선, 큰 색면, 금색/크림/갈색 중심.
- 금지: 위아래 중복 몸체, 두 번째 꼬리, 사람형 몸통, 갑옷·무기·복잡한 비늘.

후속 계획: 수정된 기준 병사 통과 후에만 공격4프레임1회 생성. 대기·전진·피격은 짧은 위치 이동으로 구현 가능. 전체 2·3성 병사 명단의 대량 제작은 아직 하지 않는다.
