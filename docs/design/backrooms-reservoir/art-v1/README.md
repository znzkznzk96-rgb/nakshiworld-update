# 저수지 어혼 아이템과 기준 병사 초안

어혼은 연성에 소모하는 인벤토리 아이템이며, PNG는 그 아이템의 화면 표시용 그림이다.

- 어혼5종: water/electric/poison/light/dark.png, 32×32 투명 원본. 제작자 검수 통과, 사용자 최종 채택 전 시안.
- soul-items-preview.png: 4배 확대 묶음.
- 기준 병사: rejected-shieldfish.png, 48×48. 형태 오류로 탈락·미적용.
- soldier-rejected-preview.png: 실패 지점 설명.
- QA.md: 검수와 실제 차감.
- SOLDIER_REVISION.md: 다음 수정안, 아직 실행하지 않음.
- *-request.json: 모델 입력과 seed.
- asset-manifest.json: 파일 해시, 크기, 투명도와 결과별 상태/사용량.

게임 코드 변경이나 배포 없음. 후속 애니메이션은 기준 병사 실패로 중단.
