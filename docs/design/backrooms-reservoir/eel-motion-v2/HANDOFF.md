# 장어 석궁병 공격 모션 v2
- 기존 64x64 파일은 사용자 픽셀 깨짐 지적으로 보류.
- 단순화한 장어 원화를 참고해 128x128 기본 스프라이트를 생성하고 공격 8프레임 제작.
- attack-sheet.png: 가로 9칸, 각 128x128. 첫 칸은 기본 자세, 나머지 8칸은 공격.
- attack-preview.gif: 확대 2배와 원본 1배 비교. 앞뒤 기본자세 정지 포함.
- 게임용 연결: 최근접 필터, 공격 프레임 1~8, 약 9fps, 반복 해제.
- 프레임 크기와 개수 확인. 사용자 최종 승인 전이며 실제 게임 연동/배포 없음.
- 남은 작업: 사용자 피드백 반영, 다른 14종 원본 및 역할별 공격/지원 모션 제작.
