# 마을 상단 소형 탐험창 v2 — 2026-10-25
사용자 최신요청을 반영한 조작 가능한 UI 검토본. **실제 Godot 게임 적용/배포는 아직 하지 않았다.**

## 반영
- 사용자 제공 마을 화면에서 방문객/수익 표시와 확대축소 안내·버튼 영역을 탐험창으로 대체. 상단 재화·장비 게이지와 마을배치는 유지.
- 창 높이는 화면의9.8%(제공628×1536 이미지 기준 약151px). 장소·퍼센트·작은 교전장면만 표시. 세로형 전투 상세창과 중복 병사카드 제거.
- 출발 후 마을로 복귀. 다른창을 열어도 진행. 완료는 작은창에 돌파/귀환 표시, 탭해야 결과창 열림.
- 실제 v0.75 `ui_theme.gd`가 적용하는 `art/ui_forest` 나무테두리/크림패널/어두운HUD/슬롯/선택테두리를 그대로 재사용. 게임폰트 neodgm의 필요한글자 subset 사용(별도이름,라이선스 동봉).
- 노선도10칸은 현관/탈의실/세면대/형광등복도/거울없는세면실/관리실/계단/여과실/반복복도/출구문 구성이 서로 다르다.
- 3·5·7라운드 중간보스,10라운드 보스 표시와 데이터 반영. 보스 능력치/보상/정식외형은 미정.
- 15종 병사 선택과3인드래그,석궁eel-motion-v4 유지. 작은창에서는 원본프레임 가로세로비를 보존.

## 사용
`NAKSHIWORLD_VILLAGE_EXPLORATION.html` 단독실행. 첫화면은 진행중 예시. 탐험창을 눌러 방구성 확인, 진행이 끝난뒤 창을 눌러 결과 확인/다음편성. 옆 검토도구에서 방/승패흐름 선택 가능. 미리보기 일시정지는 검토도구이며 실제게임 기능 아님.

마을 배경은 사용자가 제공한 스크린샷을 수정하지 않고 HTML의 밑배경으로 사용했으며 새UI를 위에 배치한 구성 검토다. 기존스크린샷의 마을버튼·재화표시는 정지된 참고화면이며 실제마을 기능이 연결된 것은 아니다. 방문객/수익 계산 및 핀치줌 제거를 구현하거나 확정하지 않았다.

배경과 방아이콘은 코드 기반 배치 시안, 적은 임시 실루엣. 추가유료생성0. 실제전투수치/회복/보상/저장 연결은 후속. 게임 전체복원 없이 game/코드를 변경하지 않았다. 최신v0.75 전체소스ZIP은SHA검증 후 UI자산만 추출해 재사용.
