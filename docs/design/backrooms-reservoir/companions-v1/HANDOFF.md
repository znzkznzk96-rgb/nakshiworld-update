# 병사 종류 추가 시안

사용자 요청: 나머지 병사 종류부터 제작하고 모션은 이후 진행.
창병: 푸른 줄무늬 물고기, 짧은 창. 의무병: 갈색 물고기, 초록 십자 구급가방.
각각 원화 기반 PixelLab 48×48 투명 PNG를 1회씩 제작. 신규 병사 디자인은 사용자 확인 전 시안.
게임 적용 및 배포 없음. 모션 제작 없음.
기존 방패병: 손가락을 방패 뒤로 숨긴 수정 원화는 사용자 승인됨. 기존 soldier-v3 네이티브 PNG에는 이 수정이 아직 반영되지 않음. 모션 전 해당 수정 필요.
다음: 신규 병사 외형 피드백을 반영하고 세 병사의 기준 이미지를 확정한 후 모션 작업.
