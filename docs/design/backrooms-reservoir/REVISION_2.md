# 백룸 화면 방향 수정 — 2026-10-24

사용자 피드백: 기존 던전선택3안 모두 미채택. 단순 번호/문 목록보다 하나의 공간으로 이어지는 게임 지도, 또는 백룸 방과 복도가 실제로 연결된 형태를 원한다. 새 시안으로 비교한다. 기존 마을 배치는 그대로 유지한다. 이전 미리보기의 임시 마을을 실제 변경안으로 해석하지 않는다.

진행 표시: 투입한 병사와 만나는 몬스터를 함께 보여주고, 서로 짧게 타격하며 승리하면 앞으로 이동한다. 진행률은 퍼센트 숫자만 남긴다. 별도 부대 체력바와 공략 게이지는 제거한다. 내부 체력 계산의 제거를 뜻하지 않는다. 이전 단일 내구도 전투 모델은 적 조우/구간 진행 구조에 맞춰 후속 수정해야 하며 이전 계산을 새 전투의 검증 결과로 인용하지 않는다.

검토할 선택화면: A 호숫가에서 비현실적 시설로 이어지는 연속 지형 지도, B 천장이 걷힌 백룸 방·복도 연결 지도(추천), C 겹친 층을 계단과 문으로 잇는 불가능한 건물 지도. 지역당10개 순차구조는 유지하고 장식 복도를 선택 가능한 분기로 오해하지 않게 한다. 맵 선택시 작은 탐험대 말이 연결 통로를 이동하고 선택 방으로 카메라가 부드럽게 따라간다. 다음 지역은 별도 지도이며 낚시터 해금 조건을 따른다.

진행창 초안: 왼쪽 편성병사3명, 오른쪽 현재 몬스터1~2명, 짧은 전진/타격/피격/물러남 연출. 몬스터를 이기면 오른쪽으로 걷고 배경이 스크롤되어 다음 적 등장. 실패시 병사들이 주저앉거나 후퇴하며 귀환 표시. 매번 방10개를 통과한다는 의미가 아니라 선택한 던전 안의 여러 조우다. 조우 수와 체력/개별탈락 정책은 아직 미정. 체력바 없이 상태를 보여주기 위한 피격깜박임/위기자세는 제안이다.

이번 이미지는 구도와 분위기를 비교하는 생성형 콘셉트 시안이다. 실제 UI 자산·병사 도트·게임구현·배포가 아니다. 마을 그림을 새로 만들거나 배치를 바꾸지 않는다.
