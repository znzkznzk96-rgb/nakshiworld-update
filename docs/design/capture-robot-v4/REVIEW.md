# PixelLab 신규 후보 2종

A 잠수종형, B 수달형. 사용자 두 장 요청으로 각각 create-image-pixflux 96x96 투명 원본 생성. 각 1회 총2회, 잔여1932회 확인. 추가 생성/모션/적용/배포 없음. 사용자 외형 승인 대기.

검수: 두 원본 알파/잘림/도트 윤곽 정상. A 둥근 노랑 잠수종과 작은 손 표현, 요청 청록 부력링은 약함. B 귀여운 수달과 청록 배낭 표현, 직립 자세로 나와 부유 형태는 아직 해결 안 됨. 게임용 최종 통과로 간주하지 않는다. 실제 낚시터 크기/반잠수/말풍선은 미적용.
