이 프로젝트는 Godot 안드로이드 낚시게임 ‘낚시월드’다. 한국어로 간결하게 답하고 요청한 작업은 직접 수행한다.
프로젝트 첨부 ZIP은 0.61 초기 복구용 백업이며 자동 최신화되지 않는다. 매 작업 시작 시 https://github.com/znzkznzk96-rgb/nakshiworld-update 의 최신 START_HERE.md, AGENTS.md, HANDOFF.md, WORK_STATE.json, CHANGELOG.md와 실제 Releases를 읽는다. 진행 중 작업 브랜치도 확인한다.
의미 있는 작업 단계마다 코드·리소스·HANDOFF·WORK_STATE를 함께 원격 저장하고 원격 커밋 SHA를 확인한다. 중간 저장은 배포 트리거 없는 work/* 브랜치에서 하며, 최신 workflow 조건을 확인한다. 실패하면 미저장 사실을 알린다.
패치마다 변경 이력과 사용자 결정, 테스트 결과, 남은 문제와 다음 작업을 기록한다. 전체 소스 ZIP·PCK·version.json이 Release에 실제 보관되는지 확인한다. 작업 중/검증 완료/배포 완료/휴대폰 적용 성공을 구분한다.
요청 범위와 승인된 UI·아트를 지키고 세이브를 보호한다. historical의 과거 소스를 최신 코드에 덮지 않는다. 토큰·서명키를 공유하지 않는다. 이미 승인된 작업은 반복 허락 없이 진행하고 중단·배포 금지 지시는 따른다.
GitHub 접근이 불가능하면 첨부 백업으로 가능한 확인을 하되 최신 상태라고 주장하지 않는다. 저장하지 못한 마지막 작업이나 모든 대화가 자동으로 복구된다고 말하지 않는다.

물고기 아트는 docs/FISH_ART_RULES.md를 먼저 읽고 따른다. 외형은 승인 시안, 색감·명암·도트 분위기는 실제 저수지 원본20종을 기준으로 한다. 임시 컬러 시안을 PixelLab 초기/스타일/색 참고 입력으로 그대로 넣지 않는다. 금빛 붕어 하나를 전 어종에 공통 적용하지 않는다. 어종별 주·보조·강조색과 핵심 특징, 참조 역할을 먼저 명세한다.
유료 생성은 한 종 생성→저수지 원본과 비교 검수→다음 종 순서로 하고 진행 중 요청은 최대1개다. 첫 결과나 중간 결과가 흐리거나 색/특징이 다르면 즉시 후속 호출을 중단한다. 잘못 나온 것을 알면서 나머지를 계속 생성하지 않는다. 후보/자동 재시도 없이 승인된 횟수를 지킨다. 거절된 계곡20종은 적용본/참조본이 아니다. 이 규칙은 남은4개 낚시터에도 동일하게 적용한다.
