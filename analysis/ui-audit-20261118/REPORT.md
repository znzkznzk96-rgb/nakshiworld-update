## 결론

전체 기능군을 대상으로 코드·격리 조작 검사와 Godot 4.4.1 실제 렌더를 점검했다. **확정 문제 3건, 기존 미완성 성장 안내 1건**을 확인했다. 치명적인 조작 불가/세이브 파괴는 이번 검사에서 재현되지 않았다. 이것은 모든 조합과 실제 Android 기기까지 무결함임을 뜻하지 않는다. 게임 코드·아트·밸런스 변경이나 배포는 하지 않았다.

기준: work/forge-138 `2821bd13207772778a34698f7d5514eb57730831`. 운영 v1.42 전체 소스 ZIP(71,985,692바이트, SHA256 f64d08576bc607cf74d922c84a2a98cd1a448a76e40551a9739d16ea437d82d5)에 작업 overlay를 적용한 /tmp/burtrun. 운영에는 없는 빠른 챔질 0.5초·팡 효과·어장 1미만 차단이 포함된다. 실제 운영 v1.42와 혼동하지 않는다.

## 방법과 판정

- 전체 기능군을 점검했지만 모든 저장 상태·모든 시간 프레임·모든 기기 조합의 전수 증명은 아니다. 자동 assertions와 실제 렌더 생성, 기능군별 대표 화면 육안 확인을 결합했다. 이미지 수에는 애니메이션 프레임/중복 상태가 포함되며 서로 다른 화면 수로 계산하지 않는다.
- 원본 실행 결과는 RUNS.json, 보완 네이티브는 SUPPLEMENT.json/MORE.json, 재실행 복원은 RESUME.json. 최종 집계는 [SUMMARY.json](SUMMARY.json): 로직 112개 중 111개 깨끗한 통과, 1개 종료 리소스 오류. 재실행 4개·네이티브 검증 5개·프리뷰 스크립트 47개 통과(검사기 수정 재실행 포함). 로그 묶음은 logs.zip, 화면 목록·해시는 logs.zip 안의 SCREEN_MANIFEST.json. 모든 원본 이미지의 원격 업로드 대신 대표 증거를 저장했다.
- 첫 실행기에서 인자를 요구하는 native 검사를 headless로 호출한 5건, PCK/서버 인자가 필요한 incremental 2건은 **검사기 호출 오류**다. native5건은 올바른 실행으로 전부 통과. incremental 2건은 이번 미검사로 남긴다. 이를 게임 오류나 통과로 계산하지 않는다.
- bundles_ui 첫 실행의 PNG 저장 오류는 출력 폴더 미생성 때문. 폴더 생성 후 재실행해 30장 정상 생성. 최초 로그는 보존한다.
- spot_unlock_audio는 기능 단정 failures=[]이나 종료 시 리소스3개 미해제 ERROR가 남음. 깨끗한 통과로 계산하지 않는다. 기존 전체 CI44226484028의 pond_empty 종료 리소스2개 미해제도 해결된 것으로 간주하지 않는다. 이번 격리 pond_empty 단정 통과와 별개다.
- 별도 시설·우편·균열 해금·균열 번들 저장 후 재실행4건 통과. 실제 사용자 세이브 대신 검사별 XDG_DATA_HOME 사용.
- 프리뷰에 표시되는 과거 버전/날짜는 테스트 fixture이며 현재 출시 버전 오류가 아니다. owned=false 로봇 관리 화면 강제 개방 등 도달 불가능한 추가 fixture는 사용자 경로 정상 판정 근거에서 제외한다. 정지 프리뷰의 애니메이션 중간 프레임도 UI 멈춤으로 판정하지 않는다.
