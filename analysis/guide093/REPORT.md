# GUIDE093 — 레이아웃 검증, 아이콘 제작 보류

승인 시안의 홈2열×4행/크림·나무/큰 그림카드/상세카드/세로스크롤 구현. 기존25주제 내용과 동적 수치 유지. 주제 목록에서 상세로 진입, 뒤로/닫기, 휠/터치드래그, 클리핑과 마지막행 접근 확인. 270×480/660 검토. 기존 낚시·우편·탐험 등 포함55개 로컬검사 통과(tests.json).

**미완성:** PixelLab 낚시 아이콘 첫1장(64×64) 결과가 시안보다 지나치게 가늘고 찌가 작아서 불합격. 1POST/1회분 차감/잔액14, 후속생성0. 불합격 PNG는게임에 적용하지 않음. 현재 UI그림은 배치검증용 기존아이콘 fallback이며 승인 시안 아이콘 완성본이 아님. 시안과거의동일한 아트라는 주장 금지. 홈8개/보석5개 최종제작 미완료.

재제작 준비: 시안 낚시아이콘 crop→64×64 nearest, 실제치수확인, init_image 포함 새요청을 pixellab/fishing/retry_request_NOT_SUBMITTED.json에 준비했으나 **제출하지 않음**. 재제작1+나머지12 =예상13회분으로 잔액14 이내. 프로젝트 지침의 불합격후중단/승인없는추가재생성금지에 따라 재제작승인 필요.

배포하지 않음. 운영 v0.92 그대로. 다음: 재제작 승인→낚시1장 검수→통과 후 잔여아이콘 순차제작→fallback 제거·시안비교·검증. 세이브/밸런스 변경 없음.
