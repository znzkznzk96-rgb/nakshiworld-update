# 지원 서브딜·유틸 시뮬레이션 — 2026-10-27

## 결론과 상태
210,000개 결정론적 전투 비교에서 보수적 조정안(refined)이 두 공격의 속도와 지원의 생존력을 구분하는 검토 후보로 적절했다. 게임 적용 확정 아님. 기존 지원 전체를 일괄상향하지 않고 공격약화형은 유지한다. 실제 addons/expedition, 공개 v0.85, 세이브·아트·유료생성 변경 없음. 앞선 HP·개별피해 표시 변경은 별도 미배포 상태다.

## 최종 검토 후보
지원도 매1.5초 기본공격. 종별 기존 ATK/HP/DEF는 유지한다.
- 등불 아귀: 생존 중 아군 일반공격 계산피해15% 증폭. 기존 적방어30%감소를 대체. 중복증폭 없음. 독틱·반사·반격 추가피해는 증폭대상 아님. 공격이후표식이 아닌 즉시 상시효과로 검증했다.
- 메기 약사: 생존 중 적공격20% 감소 유지, 중복없음.
- 미꾸라지 의무병: 2행동(3초)마다 선두 최대HP3.5% 회복, 공격 유지. 첫발동3초. 피해후 생존자에게 적용.
- 물빛 치유사: 이번 피격 후 HP가35%이하로 예상되면 피격 전에 최대HP15% 회복. 최초사용은 첫행동부터 조건부 가능, 재사용5행동(7.5초). 부활/불사 아님: 회복후에도 피해가 크면 사망.
- 약초지기: 예상피해가 최대HP8%이상이거나 현재HP50%이하면 피격전에 최대HP7.5% 보호막. 재사용3행동(4.5초), 최초첫행동부터 조건부가능. 누적보호막 상한 최대HP25%. 현행적에는 별도강공격예고가 없으므로 예고연출을 가정하지 않고 실제 피해예측으로 검사.

위 최대HP는 대상 기준이되 저육성 지원의 무임승차를 제한한다. 효과기준HP = 대상최대HP × min(1, 지원HP성장배율/대상HP성장배율). 성장배율은 현재최대HP / 해당종1성+3·IV0 기본HP이며 별·강화·개체값이 반영된다. 같은육성일 때 표의비율에 근접하며, 지원이 더낮으면 감소한다. 회복은 실제결손량, 보호막은 실제추가량만 효과로 센다. 서로다른 유틸은 함께 작동하되 동일유틸 중복발동은 팀공유주기/회복1회로 제한. 의무병은 첫생존시전자 사용; 중복동종의 육성이 다른 경우 최적시전자선택은 이번 범위에서 미구현.

유틸행동카운터/대기시간은 적교체때 유지. 만피로 새방 출발할 때 새 모델로 시작. 라운드가 아닌 적교체마다 처음부터 기다리는 현행문제를 완화한다.

## 대표 결과 — 개체값4, 각125편성
확률승률이 아니라 서로다른 편성의 통과수다. 방어선두/공격중간/비교병사후열, 모든편성의 세별·강화 동일.

|조건|두공격|기존지원|조정지원|방어+지원2|지원3|
|---|---:|---:|---:|---:|---:|
|1성+0 / 1-3|89|30|89|74|10|
|1성+3 / 1-5|116|55|120|118|59|
|1성+3 / 1-8|32|5|23|31|0|
|2성+0 / 1-9|45|5|60|76|11|
|2성+3 / 1-10|125|125|125|125|122|

2성+3 / 1-10은 두공격·조정지원 모두125편성 통과하여 생존편성 선택편향 없이 비교가능: 전투행동시간95.7초→116.1초, 종료전체HP56.1%→72.9%. 접근/전환/퇴장시간 제외이며 휴대폰체감시간 측정아님. 지원2는151.4초/80.3%, 지원3는성공122편성에서152.5초/77.7%. 다른행의 평균은 성공편성만의 평균이므로 생존조합 차이에 주의.

지원2가 1-9에서76/125로 지원1의60/125보다 강한 생존조합이 될 수 있다. 다만 성공평균전투73.6초 대57.5초로 느려진다. 무조건지원1만정답이라는 결론은 아니며, 반복파밍 속도와 돌파안정성의 선택으로 해석. 지원3은전구간최강아님.

IV0/4/8 최종후보 재확인: 1성+0 1-3 두공격65/89/113, 조정지원59/89/106. 2성+0 1-9 두공격18/45/88, 조정지원27/60/94. IV에 따른 편성경계차이가 남는다. 기존에 이야기한 ‘1-3 성장벽’은 두공격기존부터IV4에서71.2%통과였으므로 이번지원조정만으로 전체난도가기획목표에맞는다고 주장하지 않는다. 적수치/성장목표 재조정은 별도결정.

## 조사 단계
1. screen 40,000: 기본공격유지 + 약/중/강 (회복2.5/4.5/6.5%, 구조12/18/24%, 보호6/9/12%, 구조CD9/7.5/6초, 임계30/35/40%, 아귀10/15/20%). 이 단계는대상최대HP직접사용.
2. val0/4/8 90,000: 중간안 + 성장배율제한. 1성강화0/1/2/3,2성0/3,IV0/4/8,4편성유형,10방. 지원2생존편향 확인.
3. mixed 10,000: 중간안 혼합성급. 앞둘2성+3,후열1성+0/+3 또는2성+0/+3. IV4.
4. refine 20,000: 3.5/15/7.5%,구조CD7.5초/35%,아귀15%. 1/2성강화0/3,IV4,4유형,10방.
5. final0/8 40,000: 최종후보IV양끝 추가.
6. finalmixed 10,000: 최종후보 혼합성급. 1-10 앞둘2성+3에서 후열1성+0:공격120/125·지원122/125,후열2성+3은양쪽125. 강한앞둘의영향이커저육성지원이대부분통과하지만저육성공격도유사하다. 모든혼합육성문제없다는보장은아님.

## 검증 및 한계
Godot4.4.1 실제전투tick 사용. 모든조합 방어/공격/지원 각5종, 같은종중복허용,초기100%HP,한방적3연전,독·반격·회복·사망·600tick제한 그대로. seed1고정,희귀도보정0. 핵심격리검사93통과: 지원없는40조건의기존결과동일,지원5종×10방에서tick단축과실제update(.1초)50조건일치,피격전구조/적전환CD유지/저육성효과제한3검사. 운영model/view SHA256은검증파일에보존.

후보최종검증은1/2성중심이며3성희귀도/모든혼합개체값/임의배치·혼합동종지원육성은전수검증아님. 가상전투시간/HP는플레이어만족도나실기검증이아님. 실제지원효과UI,신규타이머의저장/복원은이번분석모델에연결하지않았으므로 candidate.gd를운영모델로직접교체하면안된다. 적용요청시타이머직렬화·기존전투호환·이펙트정보·안내문·전체회귀검사가필요하다.

## 재현과 원자료
`raw-results.zip`에9단계JSON과실행로그, `final-comparison.csv`에최종후보60,000전투집계. 해시/횟수는VERIFICATION.json. 분석소스는game/tests/analysis/support_utility/.

```sh
# source ZIP + work branch overlay를 복원한 전체프로젝트에서 실행
GODOT --headless --path game --script tests/analysis/support_utility/run.gd -- /tmp/screen.json screen
GODOT --headless --path game --script tests/analysis/support_utility/run.gd -- /tmp/val4.json validate 4
GODOT --headless --path game --script tests/analysis/support_utility/run.gd -- /tmp/final4.json refine 4
GODOT --headless --path game --script tests/analysis/support_utility/mixed.gd -- /tmp/mixed.json refined
GODOT --headless --path game --script tests/analysis/support_utility/verify.gd
```
validate/refine의IV를0/8로변경하여양끝재현. mixed의refined를생략하면중간안. screen은candidate_screen.gd,나머지는성장배율제한candidate.gd. 각실행은격리XDG_DATA_HOME 사용.
