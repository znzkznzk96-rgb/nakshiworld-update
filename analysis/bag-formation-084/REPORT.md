# 가방 입력·배치 UI 후속 수정 (공개 v0.83 이후, 미배포)

사용자가 v0.83에서 가방 진입과 물고기 상세 닫기에 약 5초의 일시 정지를 다시 보고했다. 이전 입력종료 누락 복구와 같은 원인으로 단정하지 않는다.

## 변경
- 가방을 열 때 0.2초 동안 입력을 무시하던 조건 제거. 열기 확대 애니메이션 및 매 프레임 글자 크기 변경 제거. 첫 화면부터 동일한 글자 크기, 즉시 선택·닫기.
- 전투 배열은 team[0]=앞 유지. 배치 표시와 슬롯 드래그만 왼쪽부터 뒤(team[2])·중간(team[1])·앞(team[0]).
- 필터 바로 위 중복 역할 범례 제거. 목록 페이지 버튼 대신 휠/터치/마우스 드래그 스크롤, 역할 변경시 스크롤 초기화. 스크롤 제스처는 편성 클릭으로 실행되지 않는다.
- 공격/방어/지원은 PixelLab 32×32 투명 PNG로 교체. 모든 역할 배지 및 강화 능력치의 공격/방어 그림은 공통 symbol 경로를 사용. HP 하트는 역할 아이콘이 아니므로 기존 유지.
- 어혼 연성·병사 합성 이미지는 비교 시안만 제시. 선택 전 실제 화면이나 합성 규칙은 바꾸지 않았다. 합성 시안의 등불아귀 역할 오표시는 지원 아이콘으로 수정하여 재제시했다.

## 검사와 한계
- 43개 격리 회귀 검사 통과(아이콘 연결 전). 새 검사: 시간 진행 없이 열기→물고기 선택→닫기, 열기 글자 크기 고정, 뒤·중간·앞/전투 배열 보존, 휠·터치 드래그, 마지막 25번째 병사 접근, 필터 검증.
- 180마리로 628×1536 화면, 새 프로세스에서 가방 6초·상세 6초 측정. 최대 프레임 간격 가방 52.004ms, 상세 25.803ms. 상세 닫기 함수 34μs, 즉시 selected=-1; 가방 닫기 true.
- Mobile/Vulkan 실행은 환경에 VK_KHR_surface가 없어 OpenGL로 자동 전환되었다. 이 결과는 데스크톱 소프트웨어 OpenGL만의 결과이며 Android/Vulkan 성능을 검증한 것이 아니다. 휴대폰의 5초 정지는 여기서 재현되지 않았고 원인 확정·실기 해결 확인은 미완료다. 입력 제한 제거/글자 크기 안정화는 확인된 코드 경로의 개선이며 휴대폰 해결 확약이 아니다.
- 기존 세이브, 개체·강화·합성·전투·보상 수치 변경 없음. 공개 서버 v0.83 유지.

## 최종 자산 연결 검증
PixelLab 세 작업 각각 10회분, 총 30회분 소모(잔여 447→417). 세 원본 RGBA 32×32, 역할별 실루엣과 투명 배경 검수. 최종 아이콘 연결 후 bag_formation/selected_ui/bag_interaction 3검사 재통과. 480/660 높이의 강화·배치 처음/끝·역할필터 총 8장 렌더링 검사 통과.
