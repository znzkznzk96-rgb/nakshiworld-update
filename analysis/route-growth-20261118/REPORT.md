## 구매·플레이 정책
- earned currency로만 구매. 어장·회복·수족관·여객선의 실제 지역별 개방/가격, 낚싯대/파츠/보관통, 기본 미끼 구매, 로봇 구매/속도/정밀/보관 강화를 적용. 없는 시설 가격을 만들지 않는다.
- smart: 기본적으로 저렴한 사용 가능 성장부터 구매하되 어장 30% 미만에서 회복 강화비를 우선 저축. 로봇 속도는 회복량의 40% 이내로 제한. 로봇 재고는 매 수동 낚시 사이 실제 collect로 회수. 어장 부족 시 로봇을 일시 정지하고 1마리분 회복 뒤 재개.
- cheap: 동일 seed17에서 저렴한 순서대로 구매, 회복 우선/로봇 속도 제한 없이 운용하는 민감도 비교 1회. 정책 변경으로 난수 소비가 달라져 정책 효과와 어종 운 차이를 분리할 수 없다.
- 지역 해금은 자격+금액 충족 시 실행. 시설을 무료로 최대 단계로 설정하지 않으며, 모든 지역에서 2회 구매 완료를 강제하지 않는다. 타일 종료의 3회 smart 모두 시설 Lv6 도달.

- 실제 물고기 무게와 보관통 한계, 번들 기부/보상, 수족관 입출고 및 동일 주인 1마리 제한, 실제 판매 함수 사용. 전시 교체는 더 높은 가격일 때만 수행.

## 측정 제한
- 캐스팅/전투는 실제 엔진 함수를 사용하되 결과 연출/이동/관리시간은 낚시당 10초로 근사. 로봇과 회복은 낚시 한 번 경과 후 1초 단위로 적분하므로 낚시 중 정확한 소비 순서에 최대 한 낚시 길이의 오차가 있다.
- 수족관은 기존 aqua_rate 평균수입을 누적하며 승객 개별 동선을 재현하지 않는다. 낚시 직후 잡은 물고기는 다음 루프에 처리해 이전 시간 수입을 소급 부여하지 않는다.
- 로컬 디스크 저장/재접속, 실제 UI 누르기, 강화 도박, 탐험, 우편 선물은 모델에서 제외. 세이브 API는 메모리 성공 처리. 플레이 시간에는 어장 회복을 기다린 접속 시간 포함.
- 최적 구매 정책 검증이 아니며 표본은 smart 3회+비교1회. 확률·가격·회복량의 게임 밸런스는 변경하지 않았다.
