# 어혼 주머니 경제·던전 보상 분석

2026-10-26. 작업 코드 반영, 공개0.80 미배포. 10R 라이선스 조건은 사용자가 의견을 물은 단계이므로 아직 적용하지 않았다.

## 선택한 수치

| 항목 | 선택 |
|---|---|
| 낚시 추가 획득 | 물고기 포획 성공마다25%, 물고기와 함께 주머니1개 |
| 주머니 내용 | 5속성 중 어혼1개, 각20% |
| 낚시상점 | 1개500비늘, 1/5/10개 묶음 구매 |
| 일반방 첫 클리어 | 주머니1개 + 기존 첫클리어 비늘(26×방번호) |
| 보스 첫 클리어 | 3R 2개,5R 3개,7R 4개,10R 5개 + 기존 첫클리어 비늘 |
| 일반방 반복 | 매회2×방번호 비늘만 지급, 주머니 없음 |
| 보스방 반복 | 매회2×방번호 비늘 + 3R5%/5R8%/7R12%/10R20%로 주머니1개 |
| 실패 | 새로 출발한 탐험은 비늘·주머니 지급 없음 |

첫클리어 확정 보상과 반복 확률 보상을 중복 지급하지 않는다. 보스 확률 결과는 출발 때 정해 저장하므로 결과창을 다시 열거나 저장을 불러와도 재추첨하지 않는다. 기존 진행중/미수령 탐험의 보상은 원래 비늘·직접 어혼 규칙을 보존한다. 기존 어혼 보유량·물고기·라이선스는 변경하지 않는다.

## 조사 방법

- Godot4.4.1의 실제 start_wait/fish_price로 저수지 어획 표본160,000개 추출. 기본미끼, 강화0, 장비부품0~3개, 어장 비율0.7/1.0. 종류·등급·크기·판매가격 생성은 게임 코드를 사용했다.
- 실제 어려운 전투 모델로 두 편성×16육성단계×10방=320전투를 실제 update(0.1)로 실행. 승패와 회복30초 포함 주기를 추출했다.
- 초기가격/드랍률 격자16조건×2,000경로=32,000. 구매예산·보스반복·낚시시간·어장상태 민감도24조건×5,000=120,000. 합계152,000가상 성장 경로.
- 고정 편성은 붕어 방패병/전기 석궁병/등불 아귀, 또는 복어 방패병/퍼치 창병/등불 아귀. 순수속성 동일 병사를 합성하면 결과를 확정할 수 있어 자원 원가를 검증할 수 있다. 개체값은4로 고정했다. 모든 편성·실제 플레이어 분포를 대표하지 않는다.
- 병사 제작/강화/동일병사 합성 비용을 누적으로 계산했다. 어혼은 속성별 재고를 각각 추적해 총량만 맞으면 된다고 가정하지 않았다. 2성 승급 후 강화0으로 초기화되는 과정도 포함했다.
- 수입은 물고기 판매이며 필수번들6종은 첫1마리를 기증해 판매수입에서 제외한다. 부품165/330/594비늘을 먼저 구매하고, 다음 병사 강화비를 남긴 뒤 정한 예산 비율만 주머니에 쓴다. 기증·판매·구매는 즉시 처리하는 가정이다.
- 기본 비교는 어장0.7, 물고기 판매 순수입의25% 이내를 주머니에 배정. 첫클리어 비늘/주머니를 받고, 막힌 방은 자원을 모아 육성한 뒤 재도전한다. 각 육성단계의 연속으로 돌파 가능한 방까지만 계산했다.

## 왜25% / 500비늘인가

같은 구매 예산25%, 어장0.7 조건의 초기격자 중앙값(성공 어획 수):

| 포획 드랍률 | 주머니 가격 | 3R 돌파 준비 | 10R 돌파 준비 | 다음지역 조건 준비(번들·10R·6600비늘) |
|---|---:|---:|---:|---:|
| 10% | 500 | 140 | 734 | 734 |
| 15% | 500 | 105 | 557 | 557 |
| 20% | 500 | 84 | 444 | 446 |
| 25% | 100 | 51 | 232 | 241 |
| 25% | 250 | 63 | 318 | 323 |
| **25%** | **500** | **70** | **371** | **374** |
| 25% | 1000 | 74 | 401 | 404 |

전투 난도는 이미 높였으므로 수급까지10~15%로 줄이면 성장 재료 대기가 과도하게 늘어났다. 100비늘은 상점 구매 비중과 가속이 커졌다. 500비늘은 기존 낚시 직접어혼25% 빈도를 유지하면서 상점을 보충 수단으로 쓰게 하는 선택이다. 이것은 선택한 설계 목표에 따른 기준값이며 유일한 최적가격이나 실측 이용자 결과라는 뜻은 아니다.

## 선택안 추가5,000경로 검증

어장0.7, 구매예산25%, 보스반복 없음:3R 준비 중앙70마리,10R 준비369마리, 번들+입장료만123마리,10R까지 포함하면371마리(90백분위475마리). 중앙 획득량은 낚시 주머니93개·구매17개였다. 상점 없이도10R 준비438마리, 통합조건439마리로 진행 가능했다.

구매예산50%면 통합조건326마리,100%면373마리였다. 100% 구매자는10R 준비 자체는283마리로 빨랐지만 입장료6600비늘을 다시 모아야 했다. 무작정 구매할수록 다음지역 해금도 빨라진다고 가정하지 않았다.

보스반복을 적극적으로 병행한 낙관적 가정(즉시 보상수령·재출발)에서는 성공어획 간격35초 기준 통합조건353마리, 반복에서 얻은 주머니 중앙6개였다. 20/60초 가정에서는361/342마리, 반복 주머니3/10개. 낚시 주머니가 주 수급원으로 유지됐다. 실제 게임에는 자동 재출발이 없으므로 이 반복 시나리오는 적극적으로 조작하는 경우에 가깝다.

## 10R 라이선스 조건 의견

권장 방향은 **필수번들 완료 + 저수지10R 최초 클리어 → 라이선스 수령**, 그 다음 기존 입장료 지불이다. 번들 기증을 막는 방식보다 두 조건을 별도로 표시하고 원하는 순서로 진행하게 하는 편이 직관적이다.

다만 모델에서 번들·입장료만 준비하는123마리에 비해10R도 요구하면371마리로 약3배가 된다. 전투 육성을 다음지역의 필수 과정으로 만드는 큰 변경이다. 첫 낚시터를 오래 즐기게 하려는 방향에는 맞지만, 단순한 조건 하나 추가처럼 가볍게 다루면 안 된다. 번들 화면에 처음부터 두 진행도를 표시하고, 이미 발급된 라이선스는 회수하지 않는 방식을 권장한다.

이 조건은 아직 게임에 적용하지 않았으며 계곡 입장 준비중 상태도 변경하지 않았다.

## 해석 한계

- 포획 성공 표본 기준이다. 챔질/파이팅 실패, 낚싯대·보관통 구매, 이동·판매 조작 시간, 수족관/오프라인 수입은 모형에 넣지 않았다. 일반미끼 비용은 어획 후 차감하는 정산 가정이다. 처음 미끼를 조달하는 과정까지 완전히 재현한 신규 세이브 실플레이가 아니다.
- 첫클리어 전투는 해당 편성이 돌파 가능한 상태인지로 판정하고 보상을 즉시 정산했다. 첫 도전 연출시간을 초 단위로 재생한 전체플레이 시뮬레이션은 아니다. 따라서 시간당 기대치나 실제 플레이 몇시간이라고 단정하지 않았다.
- 어장0.7에서는 실제 고갈에 따른 입질 대기 증가를 직접 추적하지 않는다. 어획 간격20/35/60초 민감도는 가정값이다. 어장1.0 민감도에서는 통합조건337마리였다.
- 실제 배포본의 테스트 지급(100만비늘·각속성50어혼·물고기)은 제외했다. 테스트 재화를 보유한 계정에서는 이 성장 속도를 체감할 수 없다. 기존 지급 재화를 회수하거나 삭제하지 않았다.
- 두 고정 편성/중간 개체값/정해진 육성 경로를 썼다. 유리한 혼합 조합이나 더 좋은 개체값을 선택하면 빨라질 수 있고, 더 약한 편성은 느려질 수 있다.

## 구현 검증

100,000번 포획 판정으로25% 부근의 주머니 획득과 직접어혼 미지급 확인. 개봉 시 총량 보존·5속성 균등성을 검사했다. 각방 반복10,000회씩, 총100,000회 보상 판정을 검사했으며 일반방은0개, 보스3/5/7/10R은504/816/1179/1976개였다.

구매 잔액 부족·정확한 잔액·중복구매 방지, 저장실패 시 구매/개봉/보상수령 롤백, 기존 진행중 보상 보존, 새 주머니/어혼 재접속 유지 검사를 통과했다. UI는480/660 높이에서 구매 확인·보유 개수·개봉 결과·첫클리어 보상 표시를 확인했다. 전체 검사 상태는 HANDOFF.md 참조.
