# 나뭇잎꼬리 단일 재제작
사용자 승인: 나뭇잎꼬리만1장. 어종별 색 컨셉 분리, 명확한 색상. 나머지 생성 금지.
외형: 긴 몸/작은 일반 지느러미/2갈래 넓은 톱니 잎 꼬리/잎맥. 외형은 텍스트만 전달.
색: 붉은 밤색과 밝은 구리색 몸, 에메랄드 잎 꼬리와 민트 잎맥. 이끼붕어의 동빛+짙은 이끼색과 주조색/녹색 위치/형태 차별화. 붉은 무늬 보스와는 작은 따뜻한 몸/초록 꼬리 조합으로 구분.
품질 비교 원본: 저수지 l0_09(밤색 명암), l0_12(녹색 명암), l0_00(슬림 몸 윤곽). API에는 원본 이미지를 전송하지 않음. 실제 저수지 원본 제작과 같은 Pixflux·medium shading/detail·single outline·96×64 사용.
API 시각 입력은 직접 지정한14색 팔레트1장뿐. 임시 시안·거절본·금빛 붕어·init/style 이미지 없음. 색상표 지원을 현재 공식 API schema로 확인.
추가 시도/후보 없음. 결과 검수 후 사용자에게 공유하고 중단. 최대크기·밸런스·게임·배포 변경 없음.
