## 검수 결과와 보완 대상
기존 붕어를 스타일 참조로 쓰면서 금색 계열과 잔무늬가 여러 종에 과하게 전이됨. 승인된 외형의 큰 특징은 다수 남았으나 색감/특징의 일치가 충분하지 않아 최종 적용본으로 확정하지 않음.
- 나뭇잎꼬리: 녹색 잎 꼬리가 금빛으로 치우침.
- 물방울송사리: 둥근 투명 물방울이 뚜렷하지 않음.
- 이끼붕어: 등에 난 이끼의 초록색이 약함.
- 산천어: 붉은 점과 청록 등 강조 부족.
- 폭포오름잉어: 긴 물결 지느러미는 있으나 청록색 약함.
- 구름메기: 구름 꼬리와 긴 수염이 시안보다 축소됨.
- 배후의 산천어: 붉은 테두리 반점과 검붉은 지느러미가 금빛으로 변해 보완 필요.
- 전반: 원본96×64를 넘어 임의 확대/블러 적용하지 말 것. 텍스처와 모션은 게임 적용 시 별도 확인.

## 다음 작업
사용자에게 실제 원본을 공유하고 보완 대상을 확인한다. 재생성 시 같은 금빛 붕어 참조를 전 어종에 강하게 적용하지 말고 고유색 보존을 우선한다. 이번 요청은 제작/공유이며 자동 배포하지 않는다. 최대크기는 아직 제안 단계.
